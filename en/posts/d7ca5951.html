2.1、ComfyUI 如何生成视频？

传统的 ComfyUI 文生图工作流，通常是输入提示词，经过模型采样，最终输出一张图片。

视频生成则不同。

它需要模型连续生成多帧画面，再将这些画面组合成视频。

常见的视频生成方式有三种：

生成方式 输入 输出 适用场景
文本转视频（T2V） 提示词 视频 根据文字生成视频
图片转视频（I2V） 一张图片和提示词 视频 让静态图片动起来
视频转视频（V2V） 原始视频和提示词 新视频 修改视频风格或内容

本篇主要学习图片转视频。

例如，先使用 ComfyUI 生成一张人物照片，再让人物产生轻微动作：

  • 人物自然眨眼
  • 头发轻微摆动
  • 人物转动头部
  • 镜头缓慢推进
  • 背景产生轻微动态

2.2、常见的视频生成模型

ComfyUI 本身主要提供工作流执行和节点管理能力，视频生成通常需要额外安装对应模型及节点。

目前常见的视频模型和技术路线包括：

模型或方案 主要用途 特点
Stable Video Diffusion（SVD） 图片转视频 较早期的图片动画生成方案
Wan 系列 文本转视频、图片转视频 支持多种视频生成工作流
LTX-Video 文本转视频、图片转视频 注重生成效率和视频工作流
HunyuanVideo 文本转视频等 模型规模较大，硬件要求较高
AnimateDiff 基于图像扩散模型生成动画 可与部分 Stable Diffusion 工作流结合

这些方案的模型规模、生成质量、支持分辨率和显存需求差异较大。

初学者不需要一次安装所有模型，建议先选择一个能够在当前电脑上运行的方案。

1. Stable Video Diffusion

Stable Video Diffusion（SVD）是较早应用于图片转视频的模型方案。

它可以将一张图片作为输入，生成具有连续运动效果的视频帧。

适合学习：

  • 图片转视频的基本原理
  • 视频帧生成
  • 运动幅度控制
  • 视频输出流程

但它属于较早期的视频生成方案，在人物动作和复杂场景方面存在一定局限。

2. Wan 系列

Wan是常见的视频生成模型系列，支持不同的视频生成任务。

根据具体模型版本和工作流，可以实现：

  • 图片转视频
  • 文本转视频
  • 视频生成与编辑相关任务

ComfyUI 社区有相应的工作流和节点支持。

初学者可以优先了解 Wan 的图片转视频工作流，但需要根据模型版本选择匹配的工作流，不能把不同版本的模型文件随意混用。

3. LTX-Video

LTX-Video是另一种视频生成方案，提供相应的 ComfyUI 工作流支持。

它可以用于：

  • 文本生成视频
  • 图片生成视频
  • 视频生成实验

具体支持能力取决于模型版本和当前工作流。

4. AnimateDiff

AnimateDiff 与前面的视频生成方案有所不同。

它主要通过动画模块与图像扩散模型结合，生成连续帧。

常见应用包括：

  • 人物简单动作
  • 动漫风格动画
  • 图片动态效果
  • 风格化短视频

如果已经熟悉 Stable Diffusion 文生图，可以进一步学习 AnimateDiff。

2.3、视频生成对电脑硬件有什么要求？

视频生成通常比普通图片生成更消耗资源。

原因主要有三个：

  1. 不只生成一张图片，而是需要生成多帧。
  2. 视频模型通常规模较大。
  3. 帧数、分辨率和模型精度都会影响显存占用。

1. 主要硬件指标

硬件 影响
GPU 影响模型运行速度
显存 VRAM 决定能够加载多大的模型和处理多大的任务
内存 RAM 影响模型加载、数据交换和系统稳定性
硬盘 存放模型、缓存和生成的视频
CPU 负责部分数据处理和任务调度

其中，GPU 显存通常是影响本地视频生成体验的重要因素。

2. 不同显存配置的参考

以下是选择模型时的粗略参考，不是所有模型的硬性运行门槛：

GPU 显存 建议
4GB 以图片生成和轻量视频实验为主
6GB 可以尝试部分轻量方案，但限制较多
8GB 可以研究量化模型、低显存工作流
12GB 可尝试更多轻量视频模型和优化工作流
16GB 选择范围进一步扩大
24GB 及以上 更适合本地视频生成和较复杂任务

实际需求还取决于：

  • 模型参数量
  • FP16、BF16 或量化精度
  • 视频分辨率
  • 视频帧数
  • 是否使用 CPU Offload
  • 工作流中的其他模型

不能仅凭显存大小判断某个模型一定可以运行。

3. 结合本地电脑选择模型

如果电脑只有 6GB 显存，不建议一开始就下载大型视频模型。

可以先使用：

  • 图片生成工作流
  • 低分辨率视频实验
  • 轻量模型
  • 量化模型
  • 云端 GPU 环境

如果使用的是集成显卡，视频生成能力通常会受到较大限制。

本地视频生成还需要考虑模型下载空间。一个模型可能占用数 GB 到数十 GB，安装多个模型时应提前检查硬盘容量。

三、准备 ComfyUI 视频生成环境

3.1. 确认 ComfyUI 版本

建议先更新 ComfyUI，并确认当前环境可以正常运行普通文生图工作流。

视频节点和模型通常对 ComfyUI 版本有一定要求。

如果版本过旧，可能出现：

  • 找不到节点
  • 模型无法加载
  • 工作流导入失败
  • 节点输入输出不匹配

更新之前建议备份已有工作流和配置。

3.2. 安装视频相关节点

可以通过 ComfyUI Manager 查找对应的视频节点。

例如：

  • 视频生成相关节点
  • 视频加载与处理节点
  • 视频帧合成节点
  • 视频保存节点

也可以参考 ComfyUI 官方示例和对应模型项目提供的工作流。

安装时建议遵循以下顺序：

  1. 确认要使用的视频模型。
  2. 查看模型对应的 ComfyUI 工作流。
  3. 确认需要哪些自定义节点。
  4. 安装节点及依赖。
  5. 下载模型文件。
  6. 重启 ComfyUI。
  7. 导入示例工作流并检查缺失项。

不要先安装大量节点，再寻找它们能够运行的工作流。

3.3. 下载模型文件

视频模型通常包含多个组件，例如：

  • 主模型
  • 文本编码器
  • VAE
  • 图像编码器
  • 运动模块或其他辅助模型

具体组成取决于模型架构。

下载时应以模型官方仓库或工作流说明为准，注意模型版本和文件精度。

部分模型还提供量化版本，例如 FP8 或其他低精度版本。量化可以降低显存占用，但可能影响速度或生成质量。

不要把所有模型文件都直接放到 checkpoints 目录。不同架构和节点通常有各自的模型目录要求。

四、实战：使用一张图片生成短视频

下面以通用图片转视频流程为例。

具体节点名称和连接方式，需要根据选择的模型及其工作流确定。

4.1 第一步：准备一张图片

可以使用前面教程生成的图片，也可以导入自己的照片。

建议选择：

  • 人物主体清晰
  • 构图完整
  • 人物没有被遮挡
  • 背景相对简单
  • 分辨率适中

第一次练习建议使用风景图片或简单人物图片。

如果直接使用复杂人物照片，生成过程中可能出现面部变化、手部异常等问题。

4.2 第二步：导入官方或模型对应的工作流

打开 ComfyUI，导入对应模型提供的图片转视频工作流。

可以从以下渠道查找：

  • ComfyUI 官方示例
  • 对应模型的官方仓库
  • 模型项目的使用说明
  • ComfyUI 社区工作流

优先使用与模型版本匹配的工作流。

如果工作流导入后提示缺少节点，应先安装缺失节点，不要随意删除后继续运行。

4.3 第三步：加载输入图片

在工作流中找到图片加载节点，选择准备好的图片。

通常对应 Load Image 或模型专用的图像输入节点。

检查：

  • 图片是否正确加载
  • 图片尺寸是否符合模型要求
  • 图片比例是否合理
  • 是否需要先缩放或裁剪

部分视频模型对输入图片的宽高、分辨率和比例有要求，应以工作流说明为准。

4.4 第四步：设置动作提示词

图片转视频除了输入图片，还可以通过提示词描述希望发生的运动。

例如：

中文意思：

人物轻轻转动头部，自然眨眼，头发轻微摆动，光线柔和，镜头保持固定，动作自然。

如果是风景图片，可以尝试：

建议提示词重点描述：

  • 主体动作
  • 背景变化
  • 镜头运动
  • 动作速度
  • 整体风格

不要同时要求人物做太多复杂动作。

4.5 第五步：设置视频参数

不同视频模型的参数并不完全相同，常见参数包括：

参数 作用
Width 视频帧宽度
Height 视频帧高度
Frames 生成帧数
FPS 每秒播放帧数
Steps 采样步数
Seed 随机种子
CFG 提示词影响程度，具体是否使用取决于模型
Motion Strength 运动强度，部分模型支持

其中，帧数和 FPS 决定视频时长。

4.6 第六步：运行视频生成

确认输入图片、模型和参数后，点击 Queue Prompt 运行。

视频生成通常比普通图片生成耗时更长。

第一次运行可能还需要加载模型，因此建议耐心等待。

如果出现显存不足，可以尝试：

  1. 降低视频分辨率。
  2. 减少生成帧数。
  3. 使用量化模型。
  4. 关闭其他占用显存的任务。
  5. 使用模型支持的 CPU Offload 或低显存方案。

不要一开始就使用高分辨率和大量帧数。

4.7 第七步：合成并保存视频

模型通常先生成视频帧序列，之后再通过视频合成节点输出视频文件。

工作流中可能包含：

  • Video Combine
  • VHS Video Combine
  • 其他视频合成节点

其中部分视频合成节点来自第三方扩展，例如 VideoHelperSuite。

保存时需要注意：

  • 视频格式，例如 MP4
  • 帧率
  • 编码格式
  • 是否包含音频
  • 输出目录

如果只是图片转视频，通常不会自动生成配音或背景音乐。

最终生成的视频可以在 ComfyUI 输出目录中查看。

五、视频生成效果如何优化？

视频生成不仅需要画面好看，还要保证连续帧之间的稳定性。

常见问题包括：

  • 人物面部不断变化
  • 手部形状异常
  • 人物服装发生变化
  • 背景闪烁
  • 画面出现不自然的运动
  • 镜头运动过于剧烈

可以从以下几个方面调整。

5.1. 减少动作复杂度

初次生成时，建议选择简单动作。

例如：

  • 轻微转头
  • 眨眼
  • 头发摆动
  • 云层移动
  • 水面波动

动作越复杂，模型越难保证连续帧之间的一致性。

5.2. 控制镜头运动

提示词可以明确要求：

  • Static camera：固定镜头
  • Slow zoom in：缓慢推进
  • Slow pan：缓慢平移
  • Gentle camera movement：轻微镜头运动

如果希望人物保持稳定，可以优先使用固定镜头。

5.3. 降低视频分辨率进行测试

高分辨率视频通常需要更多显存和计算资源。

建议先使用较低分辨率测试动作效果，再决定是否提高分辨率。

5.4. 注意人物一致性

图片转视频时，人物可能出现面部和服装变化。

可以尝试：

  • 使用面部清晰的输入图片
  • 简化动作提示词
  • 减少镜头变化
  • 使用模型支持的人物一致性方案
  • 避免过长的视频时长

但目前不能保证每一帧都与原始照片完全一致。

六、ComfyUI 视频生成与传统视频剪辑有什么区别？

ComfyUI 主要负责 AI 内容生成和图像处理，并不是完整的视频剪辑软件。

两者可以配合使用。

功能 ComfyUI 视频剪辑软件
AI 图片生成 支持 通常不是主要功能
图片转视频 支持，取决于模型 通常依赖外部素材或插件
AI 动作生成 支持 不是主要功能
视频裁剪 可通过节点处理 支持
添加字幕 可通过特定工作流实现 更方便
配音 需要额外模型或工具 通常更方便
音乐与音效 需要额外处理 更方便
多轨道剪辑 不是主要用途 支持

七、常见问题排查

问题 可能原因 处理方法
导入工作流后节点缺失 没有安装对应插件 安装工作流依赖
模型无法加载 模型文件路径或版本不正确 检查模型说明
显存不足 模型或视频参数过大 降低分辨率和帧数
生成时间很长 模型规模大或硬件性能不足 使用量化模型或更轻量方案
人物面部变化 视频模型难以保持身份一致性 简化动作，换用合适模型
视频背景闪烁 连续帧一致性不足 调整提示词和模型参数
视频无法保存 缺少视频合成节点或编码依赖 检查视频节点和环境
视频没有声音 图片转视频通常不自动生成音频 后期添加音频

八、练习：制作一段图片转视频短片

建议完成以下练习：

  1. 使用 ComfyUI 生成一张风景图片。
  2. 选择支持图片转视频的模型。
  3. 导入对应工作流。
  4. 设置简单的运动提示词。
  5. 设置较低分辨率和较少帧数。
  6. 生成一段短视频。
  7. 检查画面是否连续。
  8. 尝试调整动作提示词，再生成一次。
  9. 对比不同提示词的效果。

建议保存：

  • 原始图片
  • 第一次生成的视频
  • 调整提示词后的第二个视频

通过对比，理解提示词、帧数和运动设置对视频效果的影响。

九、总结

本篇学习了 ComfyUI 视频生成的基础知识：

  • 了解文本转视频、图片转视频和视频转视频
  • 认识 SVD、Wan、LTX-Video 和 AnimateDiff 等方案
  • 了解视频生成的硬件要求
  • 安装视频相关节点和模型
  • 导入图片转视频工作流
  • 设置动作提示词和视频参数
  • 生成视频帧并合成 MP4
  • 排查显存不足、人物变化和视频闪烁等问题

需要记住：ComfyUI 视频生成的核心是模型、工作流和连续帧生成，而不是简单地把一张图片转换成视频文件。
