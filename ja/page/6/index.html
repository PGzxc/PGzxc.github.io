二、认识 ComfyUI 的主要界面

ComfyUI 的核心是中间的工作流画布，其他功能围绕画布展开。

通常可以将界面理解为以下几个区域：

区域 主要作用
顶部菜单 新建、打开、保存工作流等
工作流画布 放置节点、连接节点、编辑流程
左侧面板 查看节点、模型、工作流等资源
右侧运行区域 执行工作流、查看队列和运行状态
底部工具区 访问设置、日志及其他辅助功能

具体布局可能因版本和窗口大小而变化，不必拘泥于按钮所在的位置，先理解各个区域的用途即可。

三、什么是节点？

理解节点，是学习 ComfyUI 最重要的一步。

节点就是一个独立的功能模块，每个节点负责完成某项任务。

例如：

  • 加载模型节点：读取图像生成模型。
  • 文本编码节点：处理正向或负向提示词。
  • 空 Latent 图像节点：创建指定尺寸的初始潜在图像数据。
  • KSampler 节点：执行采样生成过程。
  • VAE 解码节点：将潜在图像数据转换为普通图片。
  • 保存图像节点：保存生成结果。

这些节点各自负责不同的工作，组合起来才能形成完整的生成流程。

四、连线是什么？为什么不能随便连接？

节点之间的连线用于传递数据。

在 ComfyUI 中，连线不仅表示操作顺序，还表示一个节点的输出被另一个节点使用。

例如：

这里的采样节点需要多个输入才能工作。只有模型，并不足以完成整个图像生成过程。

4.1 如何连接节点？

一般来说，将一个节点的输出端口拖动到另一个节点对应的输入端口，就可以建立连接。

如果需要更换连接，可以根据界面支持的操作重新拖动连线，或断开原有连接后再重新连接。

具体操作可能随界面版本有所变化。

4.2 为什么有些端口不能连接？

因为不同端口传递的数据类型可能不同。

例如：

  • 模型数据不能直接当作普通图片使用。
  • 文本编码结果不能直接当作最终图像保存。
  • 潜在图像数据通常需要经过适当的解码步骤，才能得到普通图片。

可以把它理解成不同类型的插头：即使两个节点的位置很近，也不代表它们的接口一定兼容。

判断连线是否合理，关键不是看节点摆放得是否整齐，而是看数据类型和节点输入要求是否匹配。

第三篇先理解这一原则即可。后面学习具体节点时，再逐步掌握不同类型数据的连接规则。

八、常用快捷键整理

熟悉常用快捷键，可以减少反复打开菜单的操作。

以下是常见快捷键，实际使用时应以当前版本的快捷键设置为准。

快捷键 作用
Ctrl + Enter 提交当前工作流
Ctrl + Shift + Enter 将当前工作流优先提交
Ctrl + Alt + Enter 中断运行
Ctrl + S 保存工作流
Ctrl + O 打开工作流
Ctrl + Z 撤销操作
Ctrl + Y 重做操作
Ctrl + A 选择所有节点
Delete / Backspace 删除选中的节点
Ctrl + M 静音或取消静音选中的节点
Ctrl + B 绕过或取消绕过选中的节点
Space + 拖动 移动画布
双击鼠标左键 打开节点快速搜索

其中，静音和绕过是两种不同的操作，不要简单理解为删除节点。它们的实际效果与节点类型及工作流连接方式有关。

如果快捷键不起作用，可以打开设置中的快捷键面板，检查当前绑定，并根据需要进行自定义。

官方参考：ComfyUI 快捷键与自定义设置

九、动手练习：熟悉界面

了解完界面后，建议实际操作一遍。

  1. 打开 ComfyUI，找到工作流画布。
  2. 查看左侧的节点库、模型库和工作流面板。
  3. 尝试移动画布、缩放画布。
  4. 在空白处双击，打开节点搜索面板，再关闭它。
  5. 如果当前已经有工作流，尝试选中一个节点并移动位置。
  6. 使用 Ctrl + S 保存工作流。
  7. 查看运行区域，认识队列和历史记录的位置。
  8. 打开设置，找到快捷键配置。

如果当前画布是空白的，也不用着急。下一篇会继续介绍模型的基础知识，之后我们再正式搭建第一个文生图工作流。
