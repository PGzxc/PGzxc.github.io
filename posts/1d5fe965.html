ComfyUI开发之——实战之ComfyUI-AI更换照片背景(5.1)

二、相关概念

2.1、照片背景替换的基本原理

传统图片编辑通常需要使用 Photoshop 等软件手动抠图，而 ComfyUI 可以借助 AI 模型自动识别人物与背景。

整体流程如下：

需要注意：背景替换不一定需要重新生成整张图片。很多情况下，只需要识别人物区域，再将人物放到新的背景上即可。

这种方法能够较好地保留原人物的外观，但也可能出现头发边缘不自然、衣服边缘残留原背景等问题。

2.2、认识背景移除、Mask 与透明背景

在搭建工作流之前，需要先理解几个基本概念。

1. IMAGE：图片数据

ComfyUI 中的 IMAGE 通常表示图像数据。

例如：

  • 原始人物照片
  • 新背景图片
  • AI处理后的图片

图片可以传递给其他节点进行处理、合成或保存。

2. MASK：遮罩

Mask 是用来指定图片哪些区域参与处理的数据。

常见情况下：

  • 白色区域：表示需要保留或处理的区域
  • 黑色区域：表示需要排除的区域
  • 灰色区域：表示部分保留或部分处理

但需要特别注意：不同节点对 Mask 的使用约定可能不同。

例如，人物抠图节点输出的 Mask 可能表示人物区域，也可能表示背景区域。合成时如果发现人物和背景颠倒，可以尝试使用 Invert Mask 反转遮罩。

3. 透明背景与 Mask 的区别

透明背景通常通过 Alpha 通道表示，而 Mask 是单独的遮罩数据。

两者的关系可以简单理解为：

数据 作用
IMAGE 保存图片的颜色信息
MASK 指定哪些区域需要保留或处理
Alpha 表示图片像素的透明程度

部分背景移除节点会直接输出透明图片，部分节点只输出 Mask。

如果输出透明图片，可以直接进行后续合成；如果只输出 Mask，则需要使用遮罩合成节点将人物与新背景组合起来。

三、相关操作

3.1、准备背景移除模型与节点

ComfyUI 默认安装通常不包含所有专业抠图模型，因此需要根据所使用的方案安装相关节点或模型。

常见方案包括：

方案 特点 适合场景
RMBG 系列 常用于人物或物体背景移除 初学者、通用抠图
BiRefNet 擅长细节分割，适合复杂边缘 人像、头发、物体抠图
BEN2 等背景移除模型 提供背景移除能力 人像和复杂背景
SAM 系列 根据提示或区域进行分割 需要指定对象或精细调整

这些模型的效果、资源需求和支持方式并不完全相同。

1. 通过 ComfyUI Manager 安装

如果对应节点支持 Manager，可以按以下步骤操作：

  1. 打开 ComfyUI。
  2. 进入 Manager。
  3. 搜索背景移除、RMBG、BiRefNet 等相关节点。
  4. 选择对应节点包并安装。
  5. 根据提示安装依赖。
  6. 重启 ComfyUI。
  7. 在节点搜索框中确认节点是否可用。

不同版本的 Manager 界面可能有所区别。

2. 手动安装节点

如果 Manager 中没有对应节点，可以按照节点项目的官方说明进行安装。

不要直接将所有模型都放入同一个目录。 不同节点可能有自己的模型目录或模型路径配置，具体位置以项目 README 为准。

如果需要安装 Python 依赖，建议使用 ComfyUI 实际运行的 Python 环境，而不是系统中其他 Python 环境，否则可能出现“安装成功但节点仍然无法使用”的问题。

3.2、搭建背景替换工作流

本节以通用流程为例。

由于不同背景移除插件的节点名称、输入输出可能不同，以下使用功能名称描述。实际搭建时，请根据已安装节点的名称和端口进行对应。

1. 工作流结构

整体可以分成四个部分：

需要的节点大致包括：

功能 常见节点
加载人物照片 Load Image
背景移除 RMBG、BiRefNet 或其他背景移除节点
遮罩反转 Invert Mask
遮罩扩大或缩小 Grow Mask
遮罩羽化 Feather Mask、Blur Mask 或类似节点
加载新背景 Load Image
图片合成 Image Composite、ImageCompositeMasked 等
查看结果 Preview Image
保存结果 Save Image

节点名称和功能可能随 ComfyUI 版本及第三方插件变化。

2. 加载人物照片

首先添加 Load Image 节点。

选择一张人物照片作为输入。

建议初次练习使用：

  • 人物轮廓清晰的照片
  • 人物与背景颜色差异较明显的照片
  • 人物没有被其他物体大面积遮挡的照片

例如，先使用人物站在墙壁或室内背景前的照片。

不要一开始就选择头发特别复杂、人物与背景颜色接近的图片，否则可能难以判断问题来自模型还是遮罩处理。

3. 使用 AI 移除背景

添加已安装的背景移除节点，并将人物图片连接到它的图像输入端。

运行工作流后，检查输出结果。

常见输出形式有两种：

方式 A：直接输出透明图片

这种情况下，背景移除节点已经将人物与透明背景分离。

后续可以直接使用带 Alpha 通道的图片进行合成。

方式 B：输出人物图片和 Mask

这种情况下，节点可能分别输出：

  • 原始人物图像
  • 人物遮罩 Mask

需要将 Mask 连接到后续合成节点。

建议先使用 Preview Image 查看输出，确认人物区域是否正确。

4. 修正 Mask 边缘

AI 抠图并不总是完美的。

常见问题包括：

  • 人物边缘残留背景颜色
  • 头发被错误裁掉
  • 衣服边缘出现锯齿
  • 人物轮廓过于生硬
  • 背景区域残留少量人物像素

这时可以使用 Mask 处理节点。

Grow Mask：扩大或缩小遮罩

Grow Mask 可以扩大或缩小 Mask 的范围。

例如：

  • 人物边缘被裁掉：尝试适当扩大 Mask
  • 原背景残留在人物边缘：尝试适当缩小 Mask

参数方向和单位可能随节点实现有所不同，建议小幅调整并观察结果。

Feather / Blur Mask：羽化遮罩

羽化可以让人物边缘从完全保留逐渐过渡到透明，减少人物像贴纸一样的感觉。

常见效果：

  • 羽化太小：人物边缘生硬
  • 羽化太大：人物轮廓模糊，边缘容易融入背景

建议从较小的羽化范围开始，逐步调整。

对于头发、毛发等复杂边缘，普通羽化并不能完全恢复真实细节，最好使用质量较好的背景移除模型。

Invert Mask：反转遮罩

如果发现合成结果出现以下情况：

  • 人物变成透明
  • 背景被保留
  • 人物和背景的区域相反

可以尝试添加 Invert Mask。

它会将原来的黑白遮罩反转。

注意：不要在没有确认遮罩含义的情况下盲目反转。先查看 Mask 的预览结果，再决定是否需要反转。

3.3、加载新背景并进行合成

1. 加载背景图片

再添加一个 Load Image 节点，选择新的背景图片。

背景图片可以是：

  • 纯色背景
  • 室内环境
  • 户外风景
  • 办公室
  • 摄影棚背景

背景图片最好与人物照片的尺寸、构图和拍摄方向相近。

例如，人物原图是正面站立照片，背景也尽量选择视角接近、空间位置合理的图片。

2. 使用图片合成节点

添加支持 Mask 的图片合成节点，例如：

  • ImageCompositeMasked
  • 其他具有前景、背景和 Mask 输入的合成节点

通常需要连接：

输入 连接内容
Destination / Background 新背景图片
Source / Foreground 人物图片
Mask 人物遮罩

节点的输入顺序可能不同，请根据当前节点的说明确认。

如果合成后人物和背景颠倒，检查 Mask 是否需要反转。

3. 调整人物位置和尺寸

合成时还需要考虑人物的位置与大小。

如果人物在背景中显得过大或过小，可以在合成前添加图片缩放、裁剪或位置调整节点。

需要关注：

  • 人物是否处于合理的位置
  • 人物脚部是否与地面接触
  • 人物比例是否符合背景空间
  • 人物是否被背景中的物体遮挡
  • 人物头部是否与背景透视关系合理

如果背景图片和人物照片的尺寸不同，可能需要先调整背景或人物尺寸。

不要只关注图片尺寸相同，还要注意人物在画面中的实际比例。

4. 预览并保存图片

合成后添加 Preview Image，检查结果。

确认满意后，将合成结果连接到 Save Image 节点。

运行工作流，保存最终图片。

ComfyUI 通常会将图片保存到输出目录，具体位置可以在当前环境的设置或启动参数中确认。

3.4、让合成结果更自然的技巧

背景替换最容易出现的问题，不是人物有没有抠出来，而是人物放到新背景中是否自然。

1. 注意光线方向

如果人物原图的光线来自左侧，而新背景的光线来自右侧，人物可能显得不协调。

尽量选择光线方向接近的背景。

2. 注意色温

例如：

  • 人物照片偏暖色
  • 背景图片偏冷色

合成后人物容易显得突兀。

可以尝试使用亮度、对比度、色彩调整节点，让人物与背景的色调更加接近。

3. 避免人物像贴纸

人物边缘过于清晰，而背景比较模糊时，容易产生贴纸效果。

可以适当调整：

  • Mask 羽化程度
  • 人物边缘颜色
  • 背景景深
  • 人物亮度和对比度

但不要过度模糊人物轮廓，否则会影响照片质量。

4. 注意人物与背景的空间关系

人物站在地面上时，脚部位置应与背景地面合理对应。

如果人物悬空，可以尝试：

  • 调整人物位置
  • 更换背景
  • 添加合理的阴影
  • 重新选择人物和背景的组合

真实感往往取决于构图、光线和空间关系，而不仅仅是抠图精度。

四、常见问题排查

问题 可能原因 处理方法
人物边缘有白边 原背景颜色残留 缩小 Mask，尝试边缘修正
头发被裁掉 模型分割不准确 换用更适合细节的模型，调整 Mask
人物和背景颠倒 Mask 含义相反 查看 Mask，尝试 Invert Mask
人物边缘锯齿明显 Mask 边缘过于生硬 适当羽化或使用更高质量的抠图模型
人物像贴纸 光线、色温、边缘不匹配 调整颜色、边缘和背景
输出黑色背景 Alpha 或 Mask 没有正确处理 检查透明通道及合成节点
背景移除节点找不到 插件未安装或未加载 检查 Manager、节点目录和启动日志
模型无法加载 模型路径或依赖错误 查看节点项目说明和终端日志
显存不足 图片尺寸过大或模型占用较高 降低输入分辨率，关闭其他模型任务

五、练习：制作一张背景替换照片

建议按照以下步骤完成练习：

  1. 选择一张人物照片。
  2. 使用 AI 背景移除节点抠出人物。
  3. 查看人物 Mask。
  4. 尝试扩大、缩小或羽化 Mask。
  5. 加载一张新背景图片。
  6. 使用合成节点将人物放到背景中。
  7. 调整人物位置和尺寸。
  8. 保存最终图片。
  9. 对比原始抠图和修正后的效果。

建议保存两个版本：

  • 未处理 Mask 的合成结果
  • 修正 Mask 后的合成结果

这样可以直观了解遮罩修正对图片质量的影响。

六、隐私与使用注意事项

如果处理的是自己、家人或其他人的真实照片，需要注意照片隐私。

  • 优先使用本地 ComfyUI 工作流处理。
  • 不要随意将个人照片上传到不明网站。
  • 未经他人同意，不要擅自处理或传播他人的照片。
  • AI 背景移除可能改变头发、衣服等边缘细节。

本篇介绍的是通用背景替换。证件照还涉及尺寸、背景颜色、服装、姿态和具体用途的规范，不能仅凭背景替换就认定符合证件照要求。相关内容将在后续证件照实战中进一步介绍。

七、总结

本篇学习了 ComfyUI 背景替换的基本流程：

  • 使用 AI 模型移除背景
  • 理解 IMAGE、MASK 和 Alpha
  • 修正人物遮罩
  • 加载新背景
  • 合成人物与背景
  • 调整边缘、光线和人物位置
  • 保存最终图片

背景替换的核心是：正确分离人物、处理好 Mask，并让人物与新背景自然融合。
