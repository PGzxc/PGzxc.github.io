## 二、剧本制作


### 2.1、短剧示例剧本

```
剧名：《掀翻乐坛，重奏十年之声》
集数：第1集
类型：励志 / 音乐逆袭 / 都市情感
核心卖点：十年前销声匿迹的天才作曲人突然回归，一首旧曲掀翻整个乐坛，前男友和当红顶流都慌了。
```

### 2.3 、本集大纲

```
开场钩子（前3秒）：盛大音乐颁奖典礼上，当红歌手赵野正要演唱“年度金曲”，大屏幕突然被黑，响起一段十年前的钢琴旋律。

冲突：全场哗然。有人认出这是十年前一夜爆红后彻底消失的天才作曲人苏晚的作品。赵野脸色铁青，陆深（苏晚前男友，现金牌制作人）坐在评委席上手指收紧。

高潮/反转：苏晚本人竟出现在观众席最后一排，静静看着舞台。她没有上台，只是把一段完整的新编版本发到了社交平台，瞬间冲上热搜。

结尾钩子：陆深终于转头，在人群中对上苏晚的眼睛。苏晚轻轻摇头，转身离开。陆深起身追出去， tail 音落下：十年之约，才刚刚开始。
```

### 2.4 、分镜剧本

```
镜头1（0–8秒）

时间/地点：今晚，星光音乐大奖现场
画面描述：华丽舞台中央，赵野穿着闪亮舞台服，举手示意准备开唱。大屏幕播放他的宣传片，字幕“年度最热单曲”。观众欢呼。
镜头运动：从舞台大全景缓缓推到赵野特写
台词/旁白：无
情绪/音效提示：嘈杂欢呼声突然被一声刺耳的反馈音打断
预计时长：8秒

镜头2（8–18秒）

时间/地点：同上
画面描述：舞台灯光骤暗，大屏幕全部黑屏，只剩一架钢琴的剪影。一段清冷、熟悉的钢琴前奏响起（十年前的旋律）。观众席开始窃窃私语。
镜头运动：快速切几个观众错愕的脸，最后定格在评委席陆深的侧脸
台词/旁白：观众A：“这曲子……好熟？” 观众B：“十年前那个苏晚？！”
情绪/音效提示：钢琴声干净孤独，和现场的嘈杂形成反差
预计时长：10秒

镜头3（18–28秒）

时间/地点：评委席
画面描述：陆深坐在主位，手指用力抠进椅背。他眼神复杂地盯着黑屏，喉结滚动。旁边助理小声说：“陆总，这是苏晚的《十年未至》原曲……”
镜头运动：陆深手部特写 → 他抬眼的冷厉眼神
台词/旁白：陆深（低声）：“……她还敢回来。”
情绪/音效提示：钢琴声继续，带一点回响
预计时长：10秒

镜头4（28–42秒）

时间/地点：观众席最后一排
画面描述：苏晚穿着黑色高领和旧皮衣，坐在阴影里。她没有看舞台，只是低头看着手机。屏幕上是她刚发布的视频——自己用旧钢琴重新演奏并编曲的完整版《十年未至》。播放量正在疯狂跳动。
镜头运动：从她手指滑动屏幕的特写，慢慢上摇到她淡漠的侧脸
台词/旁白：无（只有钢琴声和越来越响的通知音）
情绪/音效提示：安静、克制，和场内的骚动对比
预计时长：14秒

镜头5（42–55秒）

时间/地点：舞台 + 观众席
画面描述：赵野站在台上进退两难，强笑着对主持人说“可能是系统故障”。大屏幕却突然亮起，播放苏晚发布的视频。全场沸腾，有人已经站起来录像。
镜头运动：快速交叉剪辑赵野僵硬的笑、陆深沉下的脸、苏晚平静的侧影
台词/旁白：主持人：“这……这是现场直播间也被刷爆了！”
情绪/音效提示：钢琴进入副歌，情绪上扬
预计时长：13秒

镜头6（55–70秒）

时间/地点：观众席通道
画面描述：苏晚起身，把连帽戴上，准备离开。陆深已经从评委席起身，穿过人群向她的方向走来。两人在过道两端对上视线。苏晚停下，轻轻摇了摇头，嘴角几乎不可察觉地弯了一下，然后转身走进黑暗的通道。
镜头运动：两人对视的过肩镜头，随后苏晚背影远去，陆深停在原地
台词/旁白：无
情绪/音效提示：钢琴声渐渐弱下去，只剩余韵
预计时长：15秒

镜头7（70–85秒）

时间/地点：通道尽头 → 黑屏
画面描述：苏晚走出场馆，夜风吹起她的头发。她掏出手机，屏幕上是十年前她和陆深的合影（模糊处理），以及置顶的一行字：“十年之约，今日兑现。” 她删掉合影，只留下那句话。
镜头运动：手机屏幕特写，然后拉远到她独自走在夜色里的背影
台词/旁白：苏晚（画外音，很轻）：“陆深，这次换我来掀翻乐坛。”
情绪/音效提示：风声 + 极轻的钢琴尾音
预计时长：15秒
```

### 2.5 、本集结尾

```
本集结束画面：苏晚走在夜色中的背影，字幕浮现——《掀翻乐坛，重奏十年之声》第1集完

下一集预告钩子：陆深找到苏晚租住的旧琴房，门上贴着一张泛黄的乐谱，标题是《未完成的十年》。门内传来钢琴声，却不是苏晚在弹。

需要特别注意的一致性问题：
苏晚本集全程穿黑色高领 + 旧皮衣
陆深是黑色西装，袖口微挽
钢琴旋律要固定（后期统一BGM）
```

### 2.6 、备注

```
参考风格/色调：冷色调为主，舞台用暖金对比，苏晚的戏份偏暗调、干净。
音乐建议：开场用原曲前奏，中后段用新编版本，情绪递进。
禁止出现的内容：过度煽情对白，保持克制。
本集总时长控制在 80–90 秒左右，适合竖屏完播。
```
