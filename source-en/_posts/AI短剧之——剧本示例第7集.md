## 二、剧本制作


### 2.1、短剧示例剧本

```
剧名：《掀翻乐坛，重奏十年之声》
集数：第7集
类型：励志 / 音乐逆袭 / 都市情感

核心卖点：第二段监控播出，锁门的人终于露脸。苏晚失声，陆深却在画面里看见了更残酷的真相。
```

<!--more-->

### 2.3 、本集大纲

```
开场钩子：神秘人走进房间，把笔记本转向两人，直接点击播放第二段监控。

冲突：画面里，十年前的录音棚门外，一个熟悉的身影伸手，把门锁死。苏晚认出那张脸的瞬间，整个人僵住。

高潮/反转：监控继续往下走——锁门的人并没有离开，而是靠在门上，听里面传来苏晚压抑的哭声，表情却异常平静。陆深看着画面，声音发紧：“……是她？”

结尾钩子：神秘人淡淡开口：“她不只锁了门。十年前那天晚上，她还做了另一件事。” 说完，他扔下一块旧硬盘，转身往外走。苏晚终于找回声音，只说了一个字：“等——”
```

### 2.4 、分镜剧本

```
镜头1（0–7秒）

时间/地点：地下录音工作室
画面描述：神秘人推门进来，脚步不急不慢。他没有看苏晚和陆深，只是把笔记本屏幕转向他们，点击了播放键。
镜头运动：从神秘人推门的剪影 → 他的手点击鼠标
台词/旁白：无
情绪/音效提示：鼠标点击声很轻，却异常清晰
预计时长：7秒

镜头2（7–22秒）

时间/地点：监控画面（闪回）
画面描述：第二段监控开始。十年前的录音棚门外，一个身影从侧面走近。手伸出，把门锁死。镜头角度刚好拍到侧脸——苏晚的瞳孔骤然收缩。
镜头运动：监控画面为主，快速切到苏晚失神的眼睛特写
台词/旁白：无
情绪/音效提示：监控自带的杂音，门锁“咔哒”一声
预计时长：15秒

镜头3（22–38秒）

时间/地点：工作室现实 + 监控画面
画面描述：苏晚整个人僵在原地，嘴唇动了动，却发不出声音。陆深看见她的反应，再转头看向屏幕，脸色一点点沉下去。
镜头运动：苏晚的侧脸特写 → 陆深的眼神变化
台词/旁白：陆深（声音发紧）：“……是她？”
情绪/音效提示：房间里只剩下监控的电流声
预计时长：16秒

镜头4（38–58秒）

时间/地点：监控画面继续
画面描述：锁门的人并没有离开。她靠在门板上，微微侧头，像是在听里面的动静。门内隐约传来苏晚压抑的哭声，她的表情却平静得近乎冷酷。过了很久，她才直起身，整理了一下衣领，转身离开。
镜头运动：以监控视角缓慢推进，最后定格在她离开的背影
台词/旁白：无（只有门内极轻的哭声和脚步声）
情绪/音效提示：哭声被门隔得很闷，更显压抑
预计时长：20秒

镜头5（58–75秒）

时间/地点：工作室内部
画面描述：监控播放完毕，屏幕停在黑画面。苏晚还是没有说话，只是死死盯着那块屏幕。陆深抬手，想碰她的肩，最终却只是握成了拳。
镜头运动：苏晚的手紧握成拳的特写 → 陆深收回的手
台词/旁白：无
情绪/音效提示：长久的沉默
预计时长：17秒

镜头6（75–92秒）

时间/地点：工作室内部
画面描述：神秘人从大衣口袋里拿出一块旧硬盘，放在桌上，推向两人。他的声音依旧经过处理，听不出情绪：“她不只锁了门。十年前那天晚上，她还做了另一件事。”
镜头运动：硬盘被推过来的特写 → 神秘人的手
台词/旁白：神秘人（同上）
情绪/音效提示：硬盘碰到桌面的轻响
预计时长：17秒

镜头7（92–110秒）

时间/地点：工作室门口 → 黑屏
画面描述：神秘人说完，转身就往外走。苏晚终于从僵硬中反应过来，上前一步，声音沙哑地喊出：“等——” 神秘人没有停步，门在他身后轻轻合上。桌上只剩下那块旧硬盘。
镜头运动：苏晚伸手的动作 → 门合上的背影 → 硬盘特写，画面暗下
台词/旁白：苏晚（沙哑）：“等——”
情绪/音效提示：门关上的声音很轻，却像隔绝了什么
预计时长：18秒
```

### 2.5 、本集结尾

```
本集结束画面：桌上的旧硬盘特写，字幕浮现——第7集完

下一集预告钩子：陆深把硬盘带回，阿言打开后发现里面不止监控，还有一段从未公开过的录音。录音里的第一句话，让陆深当场摔了杯子。

需要特别注意的一致性问题：
苏晚本集情绪冲击大，脸色和眼神要明显比前几集更脆弱
神秘人继续保持半遮面，不急于全貌出镜
监控画面必须做旧、加噪点，和现实严格区分
“锁门的人”身份本集只露脸、不点名，留给后续揭晓
```

### 2.6 、备注

```
参考风格/色调：继续暗调，监控画面偏灰绿杂讯感，现实部分用冷光。
节奏提示：前半段用监控直接砸真相，中段给足苏晚的失声反应，结尾用硬盘和“另一件事”甩出新悬念。
本集总时长建议控制在 105–110 秒。
音乐建议：几乎不用配乐，只保留监控杂音与环境音，强化真实压迫感。
```
