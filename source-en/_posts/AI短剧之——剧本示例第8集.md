## 二、剧本制作


### 2.1、短剧示例剧本

```
剧名：《掀翻乐坛，重奏十年之声》
集数：第8集
类型：励志 / 音乐逆袭 / 都市情感

核心卖点：硬盘里的录音被打开，第一句话就让陆深失态。十年前的真相再掀一层，苏晚却做出了谁也没想到的决定。
```

<!--more-->

### 2.2、角色设定（固定栏）

|   角色    | 年龄 |         外貌关键词（方便出图）         |       性格关键词       |              本集服装/状态               |
| :-------: | :--: | :------------------------------------: | :--------------------: | :--------------------------------------: |
| 女主 苏晚 |  28  | 清冷白皙、长直黑发、眉眼淡漠、手指修长 | 沉默寡言、倔强、有执念 | 黑色高领毛衣，头发散着，眼神比前一集更静 |
| 男主 陆深 |  30  |   锋利下颌、深目、气质清冷中带压迫感   |  骄傲、隐忍、内心柔软  |     黑衬衫袖口挽起，神情难得出现裂痕     |
| 配角 阿言 |  26  |         圆脸、戴眼镜、气质温和         |       忠诚、嘴碎       |        卫衣，坐在电脑前，表情紧张        |
|   赵野    |  27  |      精致打扮、笑容标准、眼神算计      |     圆滑、善于借势     |           本集仅电话/消息出镜            |

### 2.3 、本集大纲

```
开场钩子：阿言把硬盘接入电脑，录音文件被打开。第一句话清晰响起，陆深手里的杯子直接摔在地上。

冲突：录音内容曝光——十年前锁门的人，不只是锁门，还和赵野有过一段交易对话。苏晚的“退出”并非自愿那么简单。

高潮/反转：陆深想立刻去找苏晚，却发现苏晚先一步发了消息：“今晚十二点，旧录音棚。我有话要说。只来你一个人。”

结尾钩子：陆深赶到旧录音棚时，苏晚已经在钢琴前坐着。她没有看他，只是把一份新的乐谱推过来，标题不再是《未完成的十年》，而是一行新字：《重奏》。
```

### 2.4 、分镜剧本

```
镜头1（0–8秒）

时间/地点：陆深公司，深夜办公室
画面描述：阿言把旧硬盘接入电脑，点开唯一的音频文件。进度条开始走动，第一句话从音响里清楚响起。陆深站在一旁，手里还端着杯子。
镜头运动：电脑界面特写 → 陆深的手
台词/旁白：录音（女声，冷静）：“赵野，门我锁了。人我也留下来了。你答应的事，别忘了。”
情绪/音效提示：录音声音清晰，随后是杯子碎裂的巨响
预计时长：8秒

镜头2（8–22秒）

时间/地点：办公室
画面描述：杯子摔在地上，水渍和碎片四溅。陆深整个人僵了一秒，随即伸手撑住桌沿，指节发白。阿言吓得从椅子上弹起来。
镜头运动：碎裂的杯子特写 → 陆深低头的侧脸，眼神彻底冷下去
台词/旁白：阿言：“陆、陆总……”
情绪/音效提示：办公室里只剩下录音继续往下播放的沙沙声
预计时长：14秒

镜头3（22–40秒）

时间/地点：办公室（录音内容继续）
画面描述：录音继续。女声和赵野的声音交替出现，内容围绕“让苏晚彻底退出”“原曲版权的事交给我来处理”。陆深听完整段，才伸手把录音按停。
镜头运动：以陆深的反应为主，偶尔闪过录音波形
台词/旁白：录音中赵野（低声）：“只要她消失得干净，好处少不了你的。”
情绪/音效提示：录音被强制停止的咔哒声
预计时长：18秒

镜头4（40–55秒）

时间/地点：办公室
画面描述：陆深拿出手机，想拨苏晚的号码，却发现手机震了一下——苏晚先发来了消息：“今晚十二点，旧录音棚。我有话要说。只来你一个人。”
镜头运动：手机消息特写 → 陆深的眼睛
台词/旁白：无
情绪/音效提示：消息提示音很轻
预计时长：15秒

镜头5（55–72秒）

时间/地点：旧录音棚（夜晚）
画面描述：陆深推门进去。棚里只开了一盏灯，苏晚已经坐在钢琴前，背影笔直。她没有回头，只是把一份新的乐谱从琴架上取下，轻轻推到一旁的空位上。
镜头运动：从门口跟到苏晚的背影 → 乐谱被推过来的特写
台词/旁白：苏晚（声音很平）：“坐。”
情绪/音效提示：门关上的声音，棚内异常安静
预计时长：17秒

镜头6（72–90秒）

时间/地点：旧录音棚内
画面描述：陆深走到她身边，看见乐谱封面。原来的《未完成的十年》被划掉，上面用铅笔重新写了两个字：《重奏》。苏晚终于转过头，看着他。
镜头运动：乐谱标题特写 → 两人的对视
台词/旁白：苏晚：“十年前的那口气，我补上了。但真正要重奏的，不是那首歌。”
情绪/音效提示：无多余声音
预计时长：18秒

镜头7（90–108秒）

时间/地点：旧录音棚内 → 黑屏
画面描述：苏晚把乐谱往陆深方向又推近一点，继续说：“是我们。从头来过，或者彻底结束。你选。” 她的眼神很静，却带着一种前所未有的决绝。画面在两人的对视中暗下。
镜头运动：苏晚的眼睛特写 → 渐渐变黑
台词/旁白：苏晚（同上）
情绪/音效提示：极轻的呼吸声后，彻底安静
预计时长：18秒
```

### 2.5 、本集结尾

```
本集结束画面：苏晚与陆深的对视，字幕浮现——第8集完

下一集预告钩子：陆深没有立刻回答。他只是把《重奏》的乐谱拿起来，翻到最后一页——上面赫然写着第三个人的名字。苏晚看着他，轻声说：“现在你知道，我为什么必须自己收场了。”

需要特别注意的一致性问题：
苏晚本集情绪转为极度冷静，和前一集的失声形成对比
陆深出现明显的情绪破防（摔杯子）
《重奏》成为新的核心道具，后续会反复出现
录音内容点明赵野与锁门之人的交易，但第三人姓名本集仍不直接说破
```

### 2.6 、备注

```
参考风格/色调：办公室戏用冷白灯光，突出录音带来的冲击；旧录音棚继续用单一暖黄灯光，制造私密对峙感。

节奏提示：前半段用录音直接砸人，中段转场到旧棚，结尾用“你选”把矛盾推到最高点。

本集总时长建议控制在 105–110 秒。

音乐建议：录音段落保持原声，旧棚戏尽量静音，只靠台词和呼吸推动情绪。
```
