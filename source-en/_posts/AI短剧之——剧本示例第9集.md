## 二、剧本制作


### 2.1、短剧示例剧本

```
剧名：《掀翻乐坛，重奏十年之声》
集数：第9集
类型：励志 / 音乐逆袭 / 都市情感

核心卖点：乐谱最后一页的名字被揭开，陆深终于知道苏晚为何必须自己收场。两人之间的十年之约，到了必须给答案的时刻。
```

<!--more-->

### 2.2、角色设定（固定栏）

|   角色    | 年龄 |         外貌关键词（方便出图）         |       性格关键词       |             本集服装/状态             |
| :-------: | :--: | :------------------------------------: | :--------------------: | :-----------------------------------: |
| 女主 苏晚 |  28  | 清冷白皙、长直黑发、眉眼淡漠、手指修长 | 沉默寡言、倔强、有执念 | 黑色高领 + 旧皮衣，眼神冷静却带着疲惫 |
| 男主 陆深 |  30  |   锋利下颌、深目、气质清冷中带压迫感   |  骄傲、隐忍、内心柔软  | 黑衬衫袖口挽起，翻乐谱时手指微微发紧  |
| 配角 阿言 |  26  |         圆脸、戴眼镜、气质温和         |       忠诚、嘴碎       |            本集仅电话出镜             |


### 2.3 、本集大纲

```
开场钩子：陆深翻开《重奏》乐谱的最后一页，上面用铅笔写着一个名字。他抬眼看向苏晚，声音很低：“……为什么是她？”

冲突：苏晚没有回避，把十年前锁门之人与赵野交易的完整逻辑说清楚。她早知道真相，却一直选择自己扛。

高潮/反转：陆深问她：“那你现在把乐谱给我，是想让我一起收场，还是想让我彻底退出？” 苏晚沉默几秒，给出了答案。

结尾钩子：苏晚起身准备离开，却在门口停住。她没有回头，只是说：“明天中午，星光颁奖典礼后台。赵野会在那里。你要是来，就站在我旁边。不来，也没关系。” 门在她身后关上。
```

### 2.4 、分镜剧本

```
镜头1（0–9秒）
时间/地点：旧录音棚内
画面描述：陆深把《重奏》乐谱翻到最后一页。铅笔字迹清晰，写着一个名字。他的手指在那行字上停了很久，才抬起头。
镜头运动：乐谱最后一页特写 → 陆深抬眼的动作
台词/旁白：陆深（声音低）：“……为什么是她？”
情绪/音效提示：棚内安静，只有纸页翻动的声音
预计时长：9秒

镜头2（9–25秒）
时间/地点：旧录音棚内
画面描述：苏晚靠在琴边，没有躲闪他的视线。她开口，语速不快，却把当年的事一件件说清：锁门的人、和赵野的交易、她为何突然消失、为何现在才回来。
镜头运动：以苏晚的侧脸和陆深的反应交叉剪辑
台词/旁白：苏晚：“她锁门的时候，我就在里面。她和赵野谈条件的时候，我也听得见。我退出，不是因为你那句话，是因为我必须让他们以为自己成功了。”
情绪/音效提示：无配乐，只保留两人的呼吸和台词
预计时长：16秒

镜头3（25–42秒）
时间/地点：旧录音棚内
画面描述：陆深听完，把乐谱慢慢合上。他问出了最关键的一句：“那你现在把《重奏》给我，是想让我一起收场，还是想让我彻底退出？”
镜头运动：陆深的正面中景，眼神直视苏晚
台词/旁白：陆深（同上）
情绪/音效提示：问句落下后，短暂的死寂
预计时长：17秒

镜头4（42–60秒）
时间/地点：旧录音棚内
画面描述：苏晚沉默了几秒。她低头看了一眼自己的手指，再抬起头时，眼神已经做了决定。
镜头运动：苏晚低头的手部特写 → 她抬眼看向陆深
台词/旁白：苏晚：“我想让你知道真相。至于一起，还是退出——你自己选。我不会再求你第二次。”
情绪/音效提示：语气平静，却带着最终通牒的味道
预计时长：18秒

镜头5（60–78秒）
时间/地点：旧录音棚内
画面描述：陆深没有立刻回答。他只是把《重奏》重新打开，看着最后那页的名字，又看了看苏晚。两人对视了很久。
镜头运动：两人的过肩镜头，缓慢切换
台词/旁白：无
情绪/音效提示：只有极轻的呼吸声
预计时长：18秒

镜头6（78–95秒）
时间/地点：旧录音棚门口
画面描述：苏晚最终先动了。她拿起自己的包，走向门口。在门边停住，没有回头。
镜头运动：苏晚走向门口的背影 → 她停住的侧影
台词/旁白：苏晚：“明天中午，星光颁奖典礼后台。赵野会在那里。你要是来，就站在我旁边。不来，也没关系。”
情绪/音效提示：声音很淡，却字字清晰
预计时长：17秒

镜头7（95–112秒）
时间/地点：旧录音棚门口 → 黑屏
画面描述：苏晚说完，推门离开。门在她身后轻轻合上。陆深还站在原地，手里握着《重奏》，指节发白。他低头看了一眼最后一页的名字，终于拿起手机。
镜头运动：门合上的动作 → 陆深低头的侧脸 → 他拨出电话的手，画面暗下
台词/旁白：陆深（对着电话，声音极低）：“阿言，明天中午，星光后台。把赵野的位置盯死。”
情绪/音效提示：门关声后，只剩下他的呼吸和电话接通声
预计时长：17秒
```

### 2.5 、本集结尾

```
本集结束画面：陆深拨出电话的侧脸，字幕浮现——第9集完

下一集预告钩子：星光颁奖典礼后台。苏晚准时出现，赵野看见她的瞬间变了脸色。陆深是否会站在她旁边，成为全场最安静也最响亮的答案。

需要特别注意的一致性问题：
苏晚本集情绪是“冷静到决绝”，和之前的隐忍形成对比
《重奏》乐谱继续作为核心道具，最后一页的名字本集仍不直接念出（留给视觉或后续）
陆深最终选择拨电话，暗示他已做出决定，但观众要到下一集才看到行动
```

### 2.6 、备注

```
参考风格/色调：旧录音棚继续单一光源，突出两人对峙的私密感与压迫感。
节奏提示：前半段揭真相，中段给选择，结尾用“站在我旁边”把悬念直接甩到下一集高潮点。
本集总时长建议控制在 110 秒左右。
音乐建议：全程尽量静音，只靠台词、呼吸和纸页声推动，强化真实感。
```
