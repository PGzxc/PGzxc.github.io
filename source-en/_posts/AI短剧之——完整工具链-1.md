## 一、概述

```
下面直接给你一套能落地的完整工具链，以及一个可直接套用的剧本模板。

按这个流程走，从想法到成片会清晰很多。
```

<!--more-->

## 二、短剧完整工具链(推荐组合)

### 2.1 前期(剧本 + 分镜)

|   环节   |             推荐工具             |             说明             |
| :------: | :------------------------------: | :--------------------------: |
|  写剧本  |    豆包 / Kimi / Claude / GPT    | 让AI帮你扩写、改节奏、加反转 |
| 角色设定 |         同上 + 表格记录          | 把人物外貌、性格、服装写清楚 |
| 分镜拆解 | 飞书文档 / Notion / 语雀 / Excel |    按镜头拆，后面生成不乱    |

### 2.2 中期（出图 + 出视频）

```
推荐两条路线（可混用）：

1.路线A：快速出片（在线为主）
图片：即梦（Muse）、可灵、海螺
视频：可灵、即梦、Vidu、Runway、Luma
优点：快，人物一致性现在已经不错
适合：先验证故事好不好看

2.路线B：高质量可控（本地+在线）
图片：ComfyUI（IP-Adapter + FaceID 保脸）
视频：ComfyUI（AnimateDiff / CogVideoX / Hunyuan）+ 可灵/即梦补镜头
优点：人物更稳、风格统一
适合：系列短剧、要长期做

3.关键帧建议：先出高质量定妆照/关键帧，再图生视频，一致性会好很多。
```

### 2.3 后期（配音 + 剪辑 + 音乐）

|   环节   |                推荐工具                |           备注           |
| :------: | :------------------------------------: | :----------------------: |
|  AI配音  | 海螺AI、剪映、ElevenLabs、讯飞、Azure  | 海螺和剪映对中文情绪更好 |
| 背景音乐 |  剪映音乐库、Suno、Udio、Epic不版权曲  |      情绪匹配很重要      |
|   音效   |        剪映自带 + 免费音效网站         |    脚步、门响、心跳等    |
|   剪辑   | **剪映（强烈推荐）**、CapCut、Premiere |    短剧竖屏用剪映最快    |
|   字幕   |        剪映自动识别 + 手动微调         |      字体大、对比强      |
|   调色   |          剪映滤镜 / 简单调色           |   统一色调，系列感更强   |

### 2.4 发布与数据

```
主发：抖音、视频号、快手
次发：小红书、B站（可稍长一点）
建议同时做封面（用即梦或ComfyUI出）和标题钩子
```

## 三、完整流程一览（建议按这个顺序）

```
写剧本（含角色设定）
拆分镜表
出角色定妆照 + 关键场景图
批量出镜头图 / 直接出视频片段
AI配音
剪映里组装：画面 + 配音 + 音乐 + 字幕 + 音效
调节奏、加转场、统一调色
导出竖屏 → 发布 → 看数据改下一集
```
