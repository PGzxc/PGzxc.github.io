## 二、图片高清放大

### 2.1、为什么需要图片高清放大？

使用 ComfyUI 生成图片时，通常会受到模型、分辨率和显存的限制。

例如：

- SD 1.5 常见生成尺寸为 512×512。
- SDXL 常见生成尺寸为 1024×1024。
- 更高分辨率可能带来更大的显存占用和生成时间。

如果希望将图片用于打印、证件照、海报或高清展示，原始图片可能无法满足需求。

这时就需要使用图片高清放大（Upscale）。

但需要注意：**普通图片放大只是增加像素数量，不一定能恢复真实细节；AI 高清放大则可以利用模型重新生成或补充部分细节。**

ComfyUI 常见的图片放大方式有三种：

1. 普通图片缩放：调整图片尺寸，不主动生成新细节。
2. AI 超分辨率放大：使用专门的 Upscale Model 提升分辨率和清晰度。
3. 潜空间高清修复：放大潜空间，再通过采样重新生成细节。

下面分别介绍。

### 2.2、三种常见放大方式

#### 1. 普通图片缩放

普通缩放主要是调整图片的宽度和高度。

例如：

```
原图：512 × 512

放大后：1024 × 1024
```

可以使用 ComfyUI 中的 Image Scale 节点。

常见插值算法包括：

| 算法          | 特点                                 |
| ------------- | ------------------------------------ |
| nearest-exact | 最近邻，速度快，但容易出现像素块     |
| bilinear      | 双线性插值，结果比较平滑             |
| bicubic       | 双三次插值，通常比双线性更细腻       |
| lanczos       | 常用于图片缩放，能够保留较多边缘细节 |

普通缩放的优点是速度快、操作简单，不需要额外下载 AI 放大模型。

缺点是无法真正恢复原图中不存在的细节。放大后可能只是图片尺寸变大，并没有明显变清晰。

适合简单调整尺寸、预处理图片以及输出尺寸要求明确的场景。

#### 2. AI 超分辨率放大

AI 超分辨率（Super Resolution）使用专门训练的模型，对低分辨率图片进行放大和细节增强。

ComfyUI 常见的模型包括：

- RealESRGAN 系列。
- ESRGAN 系列。
- 其他针对人像、动漫或通用图片训练的 Upscale Model。

例如，一张 512×512 的图片，使用 4x 放大模型后，理论输出尺寸可以达到：

```
512 × 512
      ↓
2048 × 2048
```

AI 放大不仅增加像素，还可能重新生成纹理、边缘和局部细节。

不同模型的效果有所区别：

| 模型类型         | 常见用途           |
| ---------------- | ------------------ |
| RealESRGAN       | 通用图片、照片增强 |
| ESRGAN           | 图片纹理和细节增强 |
| Anime 类放大模型 | 动漫、插画         |
| 人像增强模型     | 人脸和人物细节优化 |

需要注意，AI 放大生成的细节不一定完全符合原始场景，尤其是人脸、文字和小物体，可能出现细节偏差。

#### 3. 潜空间高清修复（Latent Upscale）

潜空间高清修复与前两种方法不同。

它不是直接对最终图片进行放大，而是在潜空间中先放大图像数据，再通过 KSampler 重新采样，生成更高分辨率的图片。

基本流程：

```
文生图工作流
     ↓
生成初始潜空间
     ↓
Latent Upscale
     ↓
KSampler 重新采样
     ↓
VAE Decode
     ↓
高清图片
```

这种方式可以在放大图片的同时重新生成细节，适合改善人物、建筑和复杂场景的纹理。

但它也有缺点：

- 显存占用更高。
- 生成时间更长。
- Denoise 设置不合适时，可能改变原图构图。
- 可能出现人物面部、物体形状变化。

因此，潜空间高清修复更适合对生成图片进行二次优化，而不是单纯调整图片尺寸。

### 2.3、准备 AI 放大模型

如果使用 AI 超分辨率放大，需要准备对应的 Upscale Model。

ComfyUI 常见的模型目录：

```
ComfyUI/
└── models/
    └── upscale_models/
```

常见模型文件格式包括：

```
.pth
.safetensors
```

模型可以从 Hugging Face、GitHub 或可信的模型发布页面获取。

下载时需要注意：

1. 确认模型用途，是通用照片、人像还是动漫。
2. 确认模型支持的放大倍率。
3. 确认模型文件格式和 ComfyUI 加载节点兼容。
4. 不要下载来源不明的模型文件。

放入目录后，如果 ComfyUI 没有自动识别，可以重新启动或刷新模型列表。

## 三 实战

### 3.1、实战一：使用普通节点放大图片

先从最简单的方式开始，理解 ComfyUI 图片缩放流程。

#### 1. 添加节点

添加以下节点：

| 节点        | 作用         |
| ----------- | ------------ |
| Load Image  | 加载原图     |
| Image Scale | 调整图片尺寸 |
| Save Image  | 保存图片     |

#### 2. 连接节点

```
Load Image
    ↓ IMAGE
Image Scale
    ↓ IMAGE
Save Image
```

#### 3. 设置参数

假设原图尺寸为 512×512，希望放大到 1024×1024。

可以设置：

```
width = 1024
height = 1024
upscale_method = lanczos
```

如果节点提供保持宽高比的选项，建议开启，避免图片变形。

#### 4. 运行并查看结果

点击 Queue Prompt，生成图片。

可以分别尝试：

- nearest-exact
- bilinear
- bicubic
- lanczos

对比不同算法的效果。

这种方式适合快速调整图片尺寸，但不要将它与 AI 超分辨率混为一谈。

### 3.2、实战二：使用 AI Upscale Model 放大图片

接下来使用 AI 放大模型进行图片增强。

#### 1. 添加节点

传统 ComfyUI 工作流通常使用：

| 节点                  | 作用             |
| --------------------- | ---------------- |
| Load Image            | 加载原图         |
| UpscaleModelLoader    | 加载 AI 放大模型 |
| ImageUpscaleWithModel | 使用模型放大图片 |
| Save Image            | 保存结果         |

#### 2. 连接节点

```
Load Image
    ↓ IMAGE
ImageUpscaleWithModel
    ↓ IMAGE
Save Image

UpscaleModelLoader
    ↓ UPSCALE_MODEL
ImageUpscaleWithModel
```

#### 3. 选择模型

在 UpscaleModelLoader 中选择已经下载的模型。

例如：

```
RealESRGAN_x4plus.pth
```

不同模型名称和文件可能有所区别，以实际下载内容为准。

#### 4. 运行工作流

点击 Queue Prompt，等待图片放大完成。

如果原图是 512×512，使用 4x 模型后，输出尺寸通常为 2048×2048。

注意：模型倍率、实际输出尺寸以及显存占用需要结合具体模型和节点实现确认。

#### 5. 查看效果

建议将原图和放大后的图片放在一起对比，重点观察：

- 人物面部是否更加清晰。
- 头发和衣服纹理是否得到改善。
- 建筑边缘是否自然。
- 图片是否出现过度锐化。
- 是否产生原图中不存在的细节。

AI 放大不一定每次都更好。如果出现明显的虚假纹理或人脸变形，可以尝试更换模型。

### 3.3、实战三：潜空间放大与二次采样

如果希望在放大分辨率的同时，让模型重新生成细节，可以使用 Latent Upscale。

这里以传统 SD 1.5 文生图工作流为基础。

#### 1. 理解工作流程

普通文生图：

```
Empty Latent Image
       ↓
    KSampler
       ↓
   VAE Decode
       ↓
    Save Image
```

潜空间放大：

```
Empty Latent Image
       ↓
    KSampler
       ↓
Latent Upscale
       ↓
    KSampler 2
       ↓
   VAE Decode
       ↓
    Save Image
```

第一个 KSampler 负责生成基础图片，Latent Upscale 负责放大潜空间，第二个 KSampler 负责重新采样和细节优化。

#### 2. 添加节点

在原有文生图工作流基础上，增加：

- Latent Upscale。
- 第二个 KSampler。

具体节点名称可能因 ComfyUI 版本而略有差异。

#### 3. 连接节点

第一个 KSampler 的 LATENT 输出连接到 Latent Upscale 的 samples。

Latent Upscale 的 LATENT 输出连接到第二个 KSampler 的 latent_image。

第二个 KSampler 的 MODEL、positive、negative 可以继续使用原来的模型和提示词输出。

第二个 KSampler 的 LATENT 输出连接到 VAE Decode 的 samples。

#### 4. 设置放大参数

例如：

```
第一次生成：
width = 512
height = 512
steps = 20

Latent Upscale：
width = 768
height = 768

第二次采样：
steps = 15
denoise = 0.35
```

这里的参数仅作为 SD 1.5 的入门测试示例。

第二次采样的 Denoise 可以从 0.2～0.4 开始尝试：

- 较低：尽量保留原图结构。
- 较高：允许模型重新生成更多细节。

如果 Denoise 太高，可能导致人物、构图或物体发生变化。

#### 5. 对比结果

重点比较：

- 原图与放大图的构图是否一致。
- 人物细节是否改善。
- 纹理是否自然。
- 是否出现不必要的内容变化。

这种方式适合希望进一步优化 AI 生成图片的场景。

## 四、不同放大方法如何选择？

三种方法各有用途，不需要所有图片都使用最复杂的工作流。

| 放大方式         | 速度 | 细节增强       | 显存要求             | 适用场景        |
| ---------------- | ---- | -------------- | -------------------- | --------------- |
| Image Scale      | 快   | 基本没有       | 低                   | 调整图片尺寸    |
| AI Upscale Model | 较快 | 有             | 视模型和图片尺寸而定 | 图片清晰度增强  |
| Latent Upscale   | 较慢 | 可重新生成细节 | 较高                 | AI 图片二次优化 |

我的建议：

- 只是需要改变图片尺寸：使用 Image Scale。
- 希望图片更清晰：先尝试 AI Upscale Model。
- 希望放大后重新生成细节：使用 Latent Upscale。

也可以组合使用，例如先通过 AI 模型放大，再进行适当的细节修复。

## 五、高清放大常见问题

### 5.1. 放大后图片反而不自然

可能原因：

- 模型不适合当前图片类型。
- 模型过度增强纹理。
- 原图质量太低。
- 放大倍率过高。

建议更换模型，或者降低处理强度。

### 5.2. 放大后人脸发生变化

AI 放大可能会重新生成面部细节。

如果对人物身份和面部一致性要求较高，需要谨慎选择人像增强模型，并对结果进行人工检查。

对于证件照、纪念照等用途，不应该直接将 AI 补充的面部细节当成真实信息。

### 5.3. 显存不足

图片分辨率越高，处理时通常需要更多显存。

可以尝试：

- 降低输入图片尺寸。
- 分阶段放大，不要一次放大太多。
- 使用支持分块处理的放大节点或模型。
- 关闭其他占用显存的程序。
- 减少不必要的工作流节点。

注意，分块处理可能在接缝处出现不自然的痕迹，具体取决于节点和模型。

### 5.4. 找不到 Upscale Model

检查：

```
ComfyUI/models/upscale_models/
```

确认模型文件是否放在正确目录。

如果已经放入但列表中没有显示，可以尝试刷新模型列表或重新启动 ComfyUI。

### 5.5. 输出图片尺寸过大

例如使用 4x 放大：

```
1024 × 1024
      ↓
4096 × 4096
```

图片尺寸增大后，内存占用和处理时间也会增加。

建议根据最终用途确定输出尺寸，不要盲目追求越大越好。

## 六、本篇总结

本篇学习了 ComfyUI 的三种常见图片放大方式：

1. Image Scale：普通图片缩放，只调整尺寸。
2. AI Upscale Model：利用专门的模型增强图片细节。
3. Latent Upscale：在潜空间中放大，再通过采样重新生成细节。

需要重点理解：

- 图片放大不等于真实细节恢复。
- 不同 Upscale Model 适合不同图片类型。
- 潜空间放大可以重新生成细节，但也可能改变原图内容。
- 分辨率越高，通常对显存和处理时间的要求越高。

建议分别使用三种方法处理同一张图片，保存结果并进行对比，找到适合自己电脑和图片类型的方案。
