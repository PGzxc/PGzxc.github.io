## 二、认识 ComfyUI 的主要界面

ComfyUI 的核心是中间的工作流画布，其他功能围绕画布展开。

通常可以将界面理解为以下几个区域：

| 区域         | 主要作用                       |
| ------------ | ------------------------------ |
| 顶部菜单     | 新建、打开、保存工作流等       |
| 工作流画布   | 放置节点、连接节点、编辑流程   |
| 左侧面板     | 查看节点、模型、工作流等资源   |
| 右侧运行区域 | 执行工作流、查看队列和运行状态 |
| 底部工具区   | 访问设置、日志及其他辅助功能   |

具体布局可能因版本和窗口大小而变化，不必拘泥于按钮所在的位置，先理解各个区域的用途即可。

### 1. 工作流画布

```
画布是 ComfyUI 最重要的区域。

你可以把它理解为一张可以无限延伸的工作台。
在这里放置不同的节点，再通过连线组织生成流程。

例如，一个简单的文生图工作流可能包含：加载模型 → 文本编码 → 采样生成 → 解码图片 → 保存图片

在实际界面中，每个步骤会显示为独立的节点，而不是普通的文字框。
```

### 2. 左侧面板

```
新版界面通常会提供节点库、模型库、工作流等面板。

- 节点库（Nodes）：查找和添加节点。
- 模型库（Models）： 查看程序识别到的模型。
- 工作流（Workflows）： 管理本地工作流。
- 资源或历史相关面板： 根据版本显示生成的图片及其他内容。

如果找不到某个模型，可以先检查模型库或对应节点中的模型选择列表；
如果不知道某个节点在哪里，可以尝试从节点库搜索。
```

### 3. 运行区域与队列

```
运行区域用于执行当前工作流，并查看等待执行或正在执行的任务。

如果你连续提交多个生成任务，它们通常会进入队列等待处理。
这样就不必每生成一张图片，都重新搭建一次工作流。

后面我们还会专门介绍队列和历史记录的区别。
```

### 4.设置与日志

```
设置通常用于调整界面、语言、快捷键等选项。

日志则可以帮助你了解程序运行情况。遇到模型加载失败、节点报错或显存不足时，日志和启动终端中的错误信息往往比单纯观察界面更有帮助。

官方界面说明：ComfyUI 界面总览：https://docs.comfy.org/interface/overview)
```

## 三、什么是节点？

理解节点，是学习 ComfyUI 最重要的一步。

**节点就是一个独立的功能模块，每个节点负责完成某项任务。**

例如：

- 加载模型节点：读取图像生成模型。
- 文本编码节点：处理正向或负向提示词。
- 空 Latent 图像节点：创建指定尺寸的初始潜在图像数据。
- KSampler 节点：执行采样生成过程。
- VAE 解码节点：将潜在图像数据转换为普通图片。
- 保存图像节点：保存生成结果。

这些节点各自负责不同的工作，组合起来才能形成完整的生成流程。

### 3.1 节点由哪些部分组成？

```
常见节点通常包含以下部分：

- 标题栏： 显示节点名称，可以用来拖动节点。
- 输入端口： 接收其他节点传来的数据。
- 参数区域： 设置提示词、图片尺寸、采样步数等。
- 输出端口： 将处理结果传递给其他节点。

并非每个节点都具备全部这些部分。
有些节点只有输入输出端口，有些则提供多个参数供用户修改。
```

### 3.2 输入端口与输出端口

```
可以把节点之间的关系理解成工厂里的生产流程。

一个节点负责加工，完成后把结果交给下一个节点。输入端口负责接收数据，输出端口负责提供数据。

例如，加载模型节点输出模型对象，采样节点接收模型及其他必要输入，再生成潜在图像数据。

如果某个节点缺少必需的输入，工作流可能无法正常执行。
```

### 3.3 节点参数

```
节点中的参数决定了具体操作方式。

例如，在采样节点中，常见参数包括：

- Seed：随机种子。
- Steps：采样步数。
- CFG：提示词引导强度。
- Sampler：采样算法。

不同节点提供的参数并不相同。
初学阶段只需先知道参数属于节点本身，等学习文生图时，再逐一理解它们对结果的影响。
```

## 四、连线是什么？为什么不能随便连接？

节点之间的连线用于传递数据。

在 ComfyUI 中，连线不仅表示操作顺序，还表示一个节点的输出被另一个节点使用。

例如：

```
加载模型 ─────→ 采样节点
文本编码 ─────→ 采样节点
空 Latent 图像 → 采样节点
```

这里的采样节点需要多个输入才能工作。只有模型，并不足以完成整个图像生成过程。

### 4.1 如何连接节点？

一般来说，将一个节点的输出端口拖动到另一个节点对应的输入端口，就可以建立连接。

如果需要更换连接，可以根据界面支持的操作重新拖动连线，或断开原有连接后再重新连接。

具体操作可能随界面版本有所变化。

### 4.2 为什么有些端口不能连接？

因为不同端口传递的数据类型可能不同。

例如：

- 模型数据不能直接当作普通图片使用。
- 文本编码结果不能直接当作最终图像保存。
- 潜在图像数据通常需要经过适当的解码步骤，才能得到普通图片。

可以把它理解成不同类型的插头：即使两个节点的位置很近，也不代表它们的接口一定兼容。

**判断连线是否合理，关键不是看节点摆放得是否整齐，而是看数据类型和节点输入要求是否匹配。**

第三篇先理解这一原则即可。后面学习具体节点时，再逐步掌握不同类型数据的连接规则。

## 五、画布的基本操作

熟悉画布操作，可以让你在编辑复杂工作流时轻松很多。

### 5.1 移动画布

```
当工作流节点较多，超出当前可见范围时，可以移动画布，查看其他节点。

常见操作是按住空格键，再拖动鼠标移动画布。部分版本还提供专门的平移工具。
```

### 5.2 缩放画布

```
可以通过鼠标滚轮或界面提供的缩放工具调整画布比例，具体操作取决于当前版本和快捷键设置。

缩放主要改变工作流在屏幕上的显示大小，不会改变图片生成的分辨率。
```

### 5.3 移动节点

```
选中节点后，通常可以拖动节点标题栏，将它移动到合适的位置。

建议把节点按照处理顺序排列，例如从左到右依次放置模型加载、文本编码、采样、解码和保存节点。

这样不仅更容易阅读，后续排查问题也会更方便。
```

### 5.4 选择多个节点

```
当需要整体调整某一部分工作流时，可以使用多选操作，再一起移动节点。

节点较多时，也可以通过框选或组合功能整理相关节点。
具体支持的操作方式取决于当前界面版本。
```

### 5.5 添加节点

```
常见的添加方式包括打开节点库搜索，或者在画布空白处双击鼠标左键，调出节点快速搜索面板。

例如，想查找保存图像的节点，可以搜索 `Save Image`。

需要注意，搜索结果可能包含不同用途的节点。选择前应确认节点名称、输入输出类型和用途是否符合当前工作流。
```

## 六、工作流如何加载、保存和管理？

工作流是 ComfyUI 的核心资产之一。

一个工作流通常记录了节点、连接关系和参数等信息。保存工作流后，可以在以后继续使用，也可以分享给其他人。

### 6.1 加载工作流

```
如果你已经下载了别人分享的工作流，可以通过顶部菜单打开文件，或使用当前版本支持的导入方式加载。

常见的工作流文件格式是 JSON。

部分 PNG 图片也可能嵌入工作流信息，某些工作流还支持其他图片或文件格式。能否恢复工作流，取决于文件是否包含相关信息以及当前版本的支持情况。
```

### 6.2 保存工作流

```
编辑完成后，应及时保存。

常见的操作是通过菜单保存工作流，或者使用快捷键 `Ctrl + S`。

需要注意，保存工作流不等于保存所有模型文件。 
如果把工作流发给别人，对方可能仍然需要单独下载相应模型，并安装缺失的自定义节点和依赖。
```

### 6.3 工作流和生成图片有什么区别？

```
工作流描述的是如何生成内容，生成图片则是执行工作流后的结果。

例如：

- 工作流文件：记录节点、连接关系及参数。
- 图片文件：保存最终生成的图像。
- 模型文件：提供图像生成所需的模型能力。

三者相互配合，但不能相互替代。

如果你想复现某张图片，除了保存图片，最好也保留工作流和所需模型信息。
```

## 七、队列、运行状态与历史记录

ComfyUI 不只是搭建工作流的界面，也负责管理生成任务。

### 7.1 什么是生成队列？

```
队列可以理解成任务排队列表。

当你提交一个工作流后，ComfyUI 会根据运行情况执行任务。
如果当前有任务正在处理，后续任务可能需要等待。

例如，你准备生成 10 张不同提示词的图片，可以多次提交任务，再通过队列查看等待执行的内容。
```

### 7.2 如何提交生成任务？

```
在工作流配置完成后，可以点击界面中的运行按钮，也可以使用快捷键：Ctrl + Enter
这会将当前工作流提交执行。

提交后，任务可能需要等待，也可能立即开始。实际速度取决于硬件、模型和当前队列情况。
```

### 3. 如何中断任务？

```
如果发现参数设置错误，或者不想继续当前生成任务，可以使用界面提供的中断操作。

常见快捷键为：Ctrl + Alt + Enter

如果队列中还有其他任务，注意区分中断当前任务和清除等待任务等不同操作。
不同版本的界面可能提供不同的队列管理选项。
```

### 4. 历史记录有什么用？

```
历史记录用于查看之前执行过的任务及其生成结果，方便回顾和管理。

队列侧重于等待执行或当前运行的任务；历史记录侧重于已经执行过的任务。

两者的具体显示方式可能随版本变化。
```

## 八、常用快捷键整理

熟悉常用快捷键，可以减少反复打开菜单的操作。

以下是常见快捷键，实际使用时应以当前版本的快捷键设置为准。

| 快捷键                 | 作用                     |
| ---------------------- | ------------------------ |
| `Ctrl + Enter`         | 提交当前工作流           |
| `Ctrl + Shift + Enter` | 将当前工作流优先提交     |
| `Ctrl + Alt + Enter`   | 中断运行                 |
| `Ctrl + S`             | 保存工作流               |
| `Ctrl + O`             | 打开工作流               |
| `Ctrl + Z`             | 撤销操作                 |
| `Ctrl + Y`             | 重做操作                 |
| `Ctrl + A`             | 选择所有节点             |
| `Delete` / `Backspace` | 删除选中的节点           |
| `Ctrl + M`             | 静音或取消静音选中的节点 |
| `Ctrl + B`             | 绕过或取消绕过选中的节点 |
| `Space + 拖动`         | 移动画布                 |
| 双击鼠标左键           | 打开节点快速搜索         |

其中，静音和绕过是两种不同的操作，不要简单理解为删除节点。它们的实际效果与节点类型及工作流连接方式有关。

如果快捷键不起作用，可以打开设置中的快捷键面板，检查当前绑定，并根据需要进行自定义。

官方参考：[ComfyUI 快捷键与自定义设置](https://docs.comfy.org/zh/interface/shortcuts)

## 九、动手练习：熟悉界面

了解完界面后，建议实际操作一遍。

1. 打开 ComfyUI，找到工作流画布。
2. 查看左侧的节点库、模型库和工作流面板。
3. 尝试移动画布、缩放画布。
4. 在空白处双击，打开节点搜索面板，再关闭它。
5. 如果当前已经有工作流，尝试选中一个节点并移动位置。
6. 使用 `Ctrl + S` 保存工作流。
7. 查看运行区域，认识队列和历史记录的位置。
8. 打开设置，找到快捷键配置。

如果当前画布是空白的，也不用着急。下一篇会继续介绍模型的基础知识，之后我们再正式搭建第一个文生图工作流。

## 十、总结

本篇介绍了 ComfyUI 的主要界面，以及节点、连线、画布、工作流和生成队列等基本概念。

需要记住的核心内容有四点：

```
- 节点：负责执行具体功能。
- 连线：负责在节点之间传递数据。
- 工作流：由节点和连线组成，记录生成过程。
- 队列：负责管理提交的生成任务。
```

掌握这些基础操作后，面对复杂工作流就不容易感到陌生。
