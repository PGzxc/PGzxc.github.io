## 二、剧本制作


### 2.1、短剧示例剧本

```
剧名：《掀翻乐坛，重奏十年之声》
集数：第10集
类型：励志 / 音乐逆袭 / 都市情感

核心卖点：星光颁奖典礼后台，苏晚准时出现。赵野变脸，陆深是否站在她身边，成为十年之约最直接的答案。
```

<!--more-->

### 2.3 、本集大纲

```
开场钩子：星光颁奖典礼后台通道。苏晚从工作人员入口走进来，脚步不疾不徐。赵野正被妆发老师围着，一抬头就看见了她，笑容瞬间僵住。

冲突：赵野上前想拦，压低声音威胁。苏晚只是看他一眼，把一份文件和U盘放在他手里——正是硬盘里的录音与监控关键片段。

高潮/反转：赵野还想反扑，身后却传来陆深的声音。陆深走到苏晚身边停下，没有多余动作，只是站在那里。全场瞬间安静。

结尾钩子：苏晚侧头看了陆深一眼，极轻地弯了下嘴角。她对赵野说：“十年前你让我消失。今天，换我让你的‘真相’消失。” 说完，她和陆深一起走向舞台入口。
```

### 2.4 、分镜剧本

```
镜头1（0–8秒）
时间/地点：星光颁奖典礼后台通道
画面描述：红色应急灯与冷白灯光交错。苏晚从工作人员入口走进来，黑色西装裙装，头发挽起，气场干净而冷。路过的工作人员下意识让路。
镜头运动：从通道尽头跟拍苏晚的正面与脚步
台词/旁白：无
情绪/音效提示：高跟鞋声清晰、稳定
预计时长：8秒

镜头2（8–20秒）
时间/地点：后台化妆区
画面描述：赵野坐在镜子前，妆发老师正在做最后调整。他透过镜子看见苏晚，手里的水杯顿住，笑容彻底僵在脸上。
镜头运动：镜子中的赵野反应 → 他猛然转身
台词/旁白：无
情绪/音效提示：后台嘈杂声突然在他耳中弱下去
预计时长：12秒

镜头3（20–38秒）
时间/地点：后台通道
画面描述：赵野快步上前，挡住苏晚的去路，压低声音：“你疯了？这里是直播后台，你想怎样？” 苏晚停下，平静地看他，从包里取出一份文件和一只U盘，直接塞进他手里。
镜头运动：两人近景对峙 → U盘被塞进赵野手心的特写
台词/旁白：苏晚：“录音、监控、转账记录。原件在律师那里。你自己选，是现在主动，还是等热搜替你选。”
情绪/音效提示：语气极淡，却没有商量余地
预计时长：18秒

镜头4（38–55秒）
时间/地点：后台通道
画面描述：赵野低头看着手里的东西，脸色煞白。他抬头想再说什么，身后却突然响起陆深的声音：“让开。”
镜头运动：赵野僵住的侧脸 → 陆深从通道另一端走来的身影
台词/旁白：陆深（声音不高，却清晰）：“让开。”
情绪/音效提示：脚步声稳定，压过后台的杂音
预计时长：17秒

镜头5（55–72秒）
时间/地点：后台通道
画面描述：陆深走到苏晚身边停下。他没有碰她，也没有看赵野，只是站在那里，和苏晚并肩。空气像是被瞬间抽空，周围的工作人员都下意识停了动作。
镜头运动：两人并肩的中景 → 赵野难以置信的表情
台词/旁白：无
情绪/音效提示：短暂的死寂
预计时长：17秒

镜头6（72–90秒）
时间/地点：后台通道
画面描述：苏晚侧头，看了陆深一眼。她的嘴角极其轻微地弯了一下，随即收回目光，重新看向赵野。
镜头运动：苏晚侧脸的微表情特写 → 她直视赵野
台词/旁白：苏晚：“十年前你让我消失。今天，换我让你的‘真相’消失。”
情绪/音效提示：话音落下，后台隐约传来舞台导演的催场声
预计时长：18秒

镜头7（90–108秒）
时间/地点：后台通道通往舞台的入口 → 黑屏
画面描述：苏晚不再看赵野，转身走向舞台入口。陆深与她并肩而行。两个人的背影被舞台方向漏出的光打亮。赵野站在原地，手里还攥着那只U盘，第一次真正露出了慌乱。
镜头运动：两人并肩离去的背影 → 赵野失神的正面，画面渐渐暗下
台词/旁白：无
情绪/音效提示：舞台方向的音乐声隐约传来，随后黑屏
预计时长：18秒
```

### 2.5 、本集结尾

```
本集结束画面：苏晚与陆深并肩走向舞台光亮处的背影，字幕浮现——第10集完

下一集预告钩子：舞台上，苏晚没有唱歌，而是坐在临时架起的钢琴前，当众弹奏《重奏》。全场直播，弹幕炸裂。而赵野的“最后底牌”，也在同一时间被律师函和实锤文件彻底截停。

需要特别注意的一致性问题：
苏晚本集造型正式（黑色西装裙装），气场从“隐忍”彻底转为“主动”
陆深的出现不需要多余台词，用“站在旁边”完成十年之约的回应
赵野的崩溃要克制，重点放在他第一次真正失控的表情
```

### 2.6 、备注

```
参考风格/色调：后台用冷白+红色应急灯，突出紧张感；两人并肩时可用一点舞台暖光作为希望的暗示。
节奏提示：前半段苏晚主动施压，中段陆深出现完成站位，结尾用背影收束，把高潮留给下一集舞台。
本集总时长建议控制在 105–110 秒。
音乐建议：通道戏少用配乐，只保留环境音与脚步声；结尾可隐约漏出舞台音乐的前奏。
```
