## 二、剧本制作


### 2.1、短剧示例剧本

```
剧名：《掀翻乐坛，重奏十年之声》
集数：第3集
类型：励志 / 音乐逆袭 / 都市情感

核心卖点：赵野把十年前的旧事全抖了出去，苏晚成了众矢之的。陆深却在风口浪尖公开站台，两人之间的真相终于撕开一道口子。
```

### 2.3 、本集大纲

```
开场钩子：热搜第一：“十年前天才作曲人苏晚，其实是抄袭者？” 赵野接受采访，言之凿凿。

冲突：苏晚站在天台边缘，看着满屏骂声，陆深的电话一遍遍打进来，她全部挂断。阿言在楼下急得团团转。

高潮/反转：陆深直接发了朋友圈/微博：一张十年前的原版手稿照片，以及一句话——“曲子是我写的，她只是帮我改到了最好。骂她的人，先来骂我。” 舆论瞬间转向。

结尾钩子：苏晚终于接了电话。她声音很轻：“陆深，你不用替我洗白。十年前的事，我自己会收场。” 电话那头陆深只回了一句：“那你下楼。我在下面。” 苏晚低头，看见陆深真的站在天台对应的街道上，抬头看着她。
```

### 2.4 、分镜剧本

```
镜头1（0–8秒）

时间/地点：清晨，城市天台
画面描述：苏晚站在天台边缘，风吹起她的长发和风衣下摆。她低头看着手机，屏幕上全是热搜和骂声截图。标题刺眼：“苏晚，十年前的抄袭真相。”
镜头运动：从手机屏幕特写缓缓上摇到苏晚冷淡的侧脸
台词/旁白：无
情绪/音效提示：风声很大，手机通知音不断
预计时长：8秒

镜头2（8–20秒）

时间/地点：某采访现场（交叉剪辑）
画面描述：赵野坐在镜头前，表情痛心，说：“我其实一直想包庇她，但音乐需要真相。十年前那首成名曲，原作者另有其人……” 画面切回苏晚，她直接把手机锁屏。
镜头运动：赵野采访中景 ↔ 苏晚关掉手机的手部特写
台词/旁白：赵野（画外）：“希望她能勇敢面对。”
情绪/音效提示：采访声逐渐被风声盖过
预计时长：12秒

镜头3（20–35秒）

时间/地点：天台
画面描述：陆深的电话再次打进来，屏幕显示“陆深”两个字。苏晚看着，指尖发白，最终还是滑向了挂断。她把手机塞回口袋，抱着胳膊看向远处的城市。
镜头运动：手机震动特写 → 苏晚挂断的手指 → 她的背影
台词/旁白：无
情绪/音效提示：电话铃声被风吹散，只剩下很轻的呼吸
预计时长：15秒

镜头4（35–50秒）

时间/地点：天台下方街道 + 社交平台界面
画面描述：陆深站在街道上，阿言拿着平板急得说话。陆深没有理会，直接拿出手机，发布了一条内容：一张清晰的手稿照片（上面有他的签名和修改痕迹），配文只有一句——“曲子是我写的。她只是把它变成了最好的版本。骂她，先来骂我。”
镜头运动：陆深发帖的手机屏幕 → 快速切几个网友评论跳转的画面 → 回到陆深抬头看天台的方向
台词/旁白：阿言：“陆总，你这样会把自己也卷进去！”
情绪/音效提示：短促的发布提示音
预计时长：15秒

镜头5（50–68秒）

时间/地点：天台
画面描述：苏晚的手机再次亮起，不是电话，而是铺天盖地的转发和陆深的那条内容。她看着那张手稿，眼神第一次出现明显波动。风更大了，她终于按下了接听键。
镜头运动：苏晚接电话的侧脸特写，眼神从冷到复杂
台词/旁白：苏晚（声音很轻）：“陆深，你不用替我洗白。十年前的事，我自己会收场。”
情绪/音效提示：风声里只有她的声音
预计时长：18秒

镜头6（68–85秒）

时间/地点：天台 ↔ 街道
画面描述：电话那头，陆深沉默了两秒，只说：“那你下楼。我在下面。” 苏晚一愣，慢慢走到天台边缘往下看。镜头给到街道——陆深真的站在那里，抬头看着她，大衣被风吹得猎猎作响。两人隔空对视。
镜头运动：苏晚俯拍视角 ↔ 陆深仰拍视角，最后定格在两人的对视
台词/旁白：无
情绪/音效提示：风声达到最大，随后突然安静
预计时长：17秒

镜头7（85–100秒）

时间/地点：天台边缘 → 黑屏
画面描述：苏晚没有立刻下楼，只是抬手，把耳边的头发别到耳后。她看着下面的陆深，嘴角极其轻微地动了一下，像是要说什么，最终却只是转身，走向天台的安全出口。
镜头运动：苏晚转身的背影，风衣下摆被风掀起，画面渐渐暗下
台词/旁白：苏晚（极轻的画外音）：“……傻瓜。”
情绪/音效提示：风声渐弱，黑屏
预计时长：15秒
```

### 2.5 、本集结尾

```
本集结束画面：苏晚走进安全出口的背影，字幕浮现——第3集完

下一集预告钩子：苏晚下楼后并没有走向陆深，而是直接拦了辆车离开。陆深没有追，只是给阿言说：“去查赵野。十年前的原版小样，还在我手里。”

需要特别注意的一致性问题：
苏晚本集以黑色风衣为主，和前两集的冷色系保持统一
陆深神色明显比前两集更疲惫
热搜和手稿是关键道具，后续会继续用到
```

### 2.6 、备注

```
参考风格/色调：天台戏用冷蓝灰调，突出孤立感；陆深发帖的部分可稍微提高对比。
节奏提示：前半段压抑，中间陆深发帖是情绪转折点，最后对视留白。
本集总时长建议控制在 95–100 秒。
音乐建议：天台戏用很轻的钢琴单音或环境风声，不要喧宾夺主。
```
