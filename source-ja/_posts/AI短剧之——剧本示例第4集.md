## 二、剧本制作


### 2.1、短剧示例剧本

```
剧名：《掀翻乐坛，重奏十年之声》
集数：第4集
类型：励志 / 音乐逆袭 / 都市情感

核心卖点：苏晚独自回到十年前的旧录音棚，决定用音乐自己回应一切。陆深查到赵野的关键证据，两人却再次错过。
```

<!--more-->

### 2.2、角色设定（固定栏）

|   角色    | 年龄 |         外貌关键词（方便出图）         |       性格关键词       |                本集服装/状态                |
| :-------: | :--: | :------------------------------------: | :--------------------: | :-----------------------------------------: |
| 女主 苏晚 |  28  | 清冷白皙、长直黑发、眉眼淡漠、手指修长 | 沉默寡言、倔强、有执念 | 黑色高领 + 旧皮衣，头发随意扎起，指尖有薄茧 |

| 配角 阿言 |  26  |         圆脸、戴眼镜、气质温和         |       忠诚、嘴碎       |          卫衣，拿着文件袋跟着陆深           |

### 2.3 、本集大纲

```
开场钩子：苏晚拦下的车停在一栋几乎废弃的旧录音棚前。门牌上的字已经剥落，她却熟门熟路地推门进去。

冲突：棚里灰尘很重，那架旧钢琴还在。苏晚坐下来，开始一遍遍弹《未完成的十年》的最终段。与此同时，陆深在公司查到赵野十年前转账和聊天记录的关键截图。

高潮/反转：赵野不知怎么找来了旧录音棚外，想再施压。苏晚没有开门，只是把一段自己重新录制的钢琴版直接发到网上，配文只有一句：“原曲在此。听完再骂。”

结尾钩子：陆深赶到旧录音棚时，苏晚已经离开。门口只剩赵野被阿言拦下。陆深推开门，看见钢琴上压着一张新的乐谱——标题仍是《未完成的十年》，却多了一行小字：“差的那口气，我补上了。”
```

### 2.4 、分镜剧本

```
镜头1（0–8秒）
时间/地点：白天，城市边缘旧录音棚外
画面描述：一辆普通网约车停下。苏晚下车，抬头看向斑驳的门牌。风吹起她的头发，她把皮衣拉链拉高，推开那扇锈迹斑斑的门。
镜头运动：从门牌特写跟到苏晚推门的背影
台词/旁白：无
情绪/音效提示：门轴发出刺耳的吱呀声
预计时长：8秒

镜头2（8–22秒）
时间/地点：旧录音棚内
画面描述：光线从高窗漏进来，灰尘在光柱里浮动。正中是一架蒙尘的钢琴。苏晚走过去，用袖子随便擦了擦琴键，坐下，开始弹《未完成的十年》的最后一段。弹得很慢，却比之前任何一次都完整。
镜头运动：灰尘光柱 → 苏晚坐下的侧影 → 手指在琴键上的特写
台词/旁白：无（只有钢琴声）
情绪/音效提示：钢琴声在空旷的棚里带出回响
预计时长：14秒

镜头3（22–38秒）
时间/地点：陆深公司办公室（交叉剪辑）
画面描述：陆深站在落地窗前，阿言把平板递过来。屏幕上是赵野十年前的转账记录和几段聊天截图，内容隐约指向“买断”和“封口”。陆深看完，眼神彻底冷下来。
镜头运动：平板内容快速闪过 → 陆深捏紧平板边缘的手
台词/旁白：阿言：“陆总，这些够不够？”
陆深：“够让他身败名裂。”
情绪/音效提示：办公室很安静，只有空调声
预计时长：16秒

镜头4（38–52秒）
时间/地点：旧录音棚外
画面描述：赵野站在门口， dual 手插兜，脸上带着惯有的笑。他敲了敲门，提高声音：“苏晚，出来谈谈？我给你最后一次机会，合作对大家都好。” 棚内钢琴声没有停。
镜头运动：赵野敲门的手部特写 → 门内透出的钢琴声
台词/旁白：赵野（笑着）：“别敬酒不吃吃罚酒。”
情绪/音效提示：敲门声和钢琴声叠在一起
预计时长：14秒

镜头5（52–70秒）
时间/地点：旧录音棚内
画面描述：苏晚弹完最后一声，没有理会外面。她拿出手机，把刚刚录下的完整钢琴版上传，配文只有一行字：“原曲在此。听完再骂。” 发送成功后，她把手机扣在琴谱上，靠着椅背闭了闭眼。
镜头运动：手机发送界面特写 → 苏晚闭眼的侧脸
台词/旁白：无
情绪/音效提示：发送提示音很轻，随后是长久的安静
预计时长：18秒

镜头6（70–88秒）
时间/地点：旧录音棚门口
画面描述：陆深的车急刹停下。他下车就看见赵野还在门口，阿言已经上前把人拦住。陆深看都不看赵野一眼，直接推开录音棚的门。
镜头运动：车门甩上 → 陆深快步推门的背影
台词/旁白：阿言（对赵野）：“现在请你离开。”
情绪/音效提示：脚步声急促
预计时长：18秒

镜头7（88–105秒）
时间/地点：旧录音棚内 → 黑屏
画面描述：棚里已经空了。只有钢琴上压着一张新的乐谱，标题仍是《未完成的十年》，下面多了一行铅笔小字：“差的那口气，我补上了。” 陆深走过去，拿起那张谱，指尖在那行字上停了很久。
镜头运动：乐谱特写 → 陆深低头看着它的侧脸，画面渐渐暗下
台词/旁白：无
情绪/音效提示：极轻的风从破窗灌进来
预计时长：17秒
```

### 2.5 、本集结尾

```
本集结束画面：陆深独自站在旧录音棚里，手里拿着那张新乐谱，字幕浮现——第4集完

下一集预告钩子：苏晚的原曲视频播放量暴涨，舆论开始分裂。赵野被逼到墙角，决定放出“最后底牌”。而苏晚收到一条匿名短信：“十年前那天晚上的监控，我还留着。”

需要特别注意的一致性问题：
苏晚服装继续延续黑色高领 + 旧皮衣
旧录音棚作为重要场景，后续可能还会用到
《未完成的十年》的乐谱是核心道具，字迹要统一
```

### 2.6 、备注

```
参考风格/色调：旧录音棚用高对比的灰尘光影，突出荒废与记忆感；陆深办公室偏冷净。
节奏提示：前半段用钢琴撑气氛，中间交叉剪辑加快信息量，结尾留白。
本集总时长建议控制在 100 秒左右。
音乐建议：棚内戏全程用苏晚弹的钢琴版，不要额外配乐。
```
