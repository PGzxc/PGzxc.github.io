## 二、剧本制作


### 2.1、短剧示例剧本

```
剧名：《掀翻乐坛，重奏十年之声》
集数：第6集
类型：励志 / 音乐逆袭 / 都市情感

核心卖点：苏晚独自赴约，陆深却先一步赶到。十年前的监控真正露面，里面的人，却让两人都沉默了。
```

### 2.3 、本集大纲

```
开场钩子：苏晚按短信地址，来到一栋停业已久的地下录音工作室。门虚掩着，里面只有一盏灯。

冲突：她推门进去，发现陆深已经在里面。两人对视，谁都没先说话。桌上放着一台旧笔记本，屏幕亮着，正是“十年前那天晚上的监控”。

高潮/反转：监控开始播放。画面里不是外人，而是十年前的苏晚和陆深本人——他们在争吵，苏晚哭着说“我退出”，陆深则摔门而去。监控在关键时刻被人从外面锁上了门。

结尾钩子：笔记本突然弹出一行字：“真正的监控，在下一段。想看完整的，就留下来。” 与此同时，门外传来脚步声。苏晚和陆深同时抬头。
```

### 2.4 、分镜剧本

```
镜头1（0–8秒）

时间/地点：夜晚，停业的地下录音工作室门口
画面描述：苏晚站在台阶下，确认了短信里的地址。门没有锁，虚掩着，里面透出一点灯光。她深吸一口气，推门走了进去。
镜头运动：从门牌号码特写跟到苏晚推门的背影
台词/旁白：无
情绪/音效提示：门轴轻微的吱呀声，外面的车声被隔绝
预计时长：8秒

镜头2（8–20秒）

时间/地点：地下录音工作室内部
画面描述：房间不大，灰尘很重。正中的桌子上放着一台旧笔记本电脑，屏幕亮着。陆深已经站在桌边，听到开门声转过身。两人隔着一张桌子对视。
镜头运动：先给笔记本屏幕的光 → 再给两人的对视中景
台词/旁白：苏晚（声音很淡）：“你怎么会在这里？”
陆深：“我查到了同一个地址。”
情绪/音效提示：空气安静得能听到彼此的呼吸
预计时长：12秒

镜头3（20–35秒）

时间/地点：工作室内部
画面描述：陆深侧过身，让苏晚能看见屏幕。监控画面已经暂停在某一帧——十年前的录音棚门口，苏晚站在门内，陆深站在门外。苏晚的手指微微收紧。
镜头运动：笔记本屏幕特写（模糊处理十年前的两人）→ 苏晚的侧脸
台词/旁白：苏晚（低声）：“……这不是全部。”
情绪/音效提示：笔记本风扇很轻的声音
预计时长：15秒

镜头4（35–55秒）

时间/地点：监控画面（闪回）
画面描述：监控开始播放。十年前的苏晚红着眼睛说：“陆深，我退出。这首歌，我不要了。” 陆深站在门外，声音发冷：“你退出可以，但别后悔。” 随后他转身离开，门外有人伸手，把录音棚的门从外面锁上了。
镜头运动：以监控画面的视角为主，偶尔切回现实中两人的反应
台词/旁白：监控里的对话如上
情绪/音效提示：监控自带的电流声和杂音
预计时长：20秒

镜头5（55–70秒）

时间/地点：工作室内部
画面描述：监控画面停住。苏晚看着屏幕，很久没有说话。陆深的手握成拳，又慢慢松开。他开口，声音比刚才低：“那天晚上，门不是我锁的。”
镜头运动：苏晚的侧脸特写 → 陆深的手部特写
台词/旁白：陆深：“我回来的时候，门已经锁上了。你没接电话，我以为你……不想再见到我。”
情绪/音效提示：房间里只剩下笔记本的风扇声
预计时长：15秒

镜头6（70–88秒）

时间/地点：工作室内部
画面描述：笔记本屏幕突然自己跳转，弹出一行黑底白字：“真正的监控，在下一段。想看完整的，就留下来。” 光标在闪烁。苏晚和陆深同时看向门口。
镜头运动：屏幕文字特写 → 两人抬头的动作
台词/旁白：无
情绪/音效提示：门外隐约传来的脚步声
预计时长：18秒

镜头7（88–105秒）

时间/地点：工作室门口 → 黑屏
画面描述：门被从外面轻轻推开一条缝。一只手出现在门边，却没有立刻进来。苏晚下意识往前走了半步，陆深伸手挡住了她。两人的目光都落在那只手上。
镜头运动：门缝与手的特写 → 苏晚和陆深的侧脸，画面渐渐暗下
台词/旁白：门外传来经过处理的声音：“十年了。终于等到你们一起出现。”
情绪/音效提示：声音低沉，带电子失真
预计时长：17秒
```

### 2.5 、本集结尾

```
本集结束画面：门缝中的手与两人的对视，字幕浮现——第6集完

下一集预告钩子：神秘人走进来，把第二段监控播放给两人看。画面里出现了第三个身影——正是当年把门锁上的人。而那个人的脸，让苏晚瞬间失声。

需要特别注意的一致性问题：
苏晚继续黑高领 + 旧皮衣
地下工作室光线要暗，主要靠笔记本屏幕和一盏灯照明
监控画面需做旧、加噪点，和现实画面区分开
```

### 2.6 、备注

```
参考风格/色调：整体偏暗，冷色调，只有笔记本屏幕和那一盏灯提供光源，营造压抑感。
节奏提示：前半段对峙，中间用监控闪回推情绪，结尾用门外脚步声收住。
本集总时长建议控制在 100–105 秒。
音乐建议：尽量少用配乐，以环境音和监控杂音为主，突出真实感。
```
