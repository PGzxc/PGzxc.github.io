## 二、本地图 & 视频生成

代表工具：

```
ComfyUI、Stable Diffusion WebUI（Automatic1111）、Forge、Fooocus、InvokeAI
```

### 2.1 图片生成流程

1-常用工具对比

|     工具      |        特点         |    适合人群    |
| :-----------: | :-----------------: | :------------: |
|    ComfyUI    | 节点式，可控性最强  | 想深度定制的人 |
| WebUI (A1111) | 界面直接，功能全面  |    新手入门    |
|     Forge     | WebUI优化版，速度快 |  显存不大的人  |
|    Fooocus    | 最傻瓜，出图质量高  |  只想快速出图  |

2-完整制作步骤

```
1、环境准备
 安装显卡驱动 + CUDA
 准备 Python / Git
 下载对应软件（推荐整合包）
 建好模型文件夹（checkpoints、loras、vae、controlnet、upscale）

2、模型准备
 底模（Checkpoint）：写实、动漫、二次元、国风等
 LoRA：人物一致性、风格、服装、动作
 VAE（影响色彩）
 Embedding / Textual Inversion
 ControlNet 模型（姿势、深度、线稿、IP-Adapter 等）
 Upscale 模型（4x-UltraSharp、ESRGAN 等）

3、提示词写法
 正向提示词（主体 + 细节 + 风格 + 光影 + 画质词）
 反向提示词（常见负面词库）
 权重控制（(word:1.3) 或 ComfyUI 的权重节点）
 中文提示词 vs 英文提示词（本地模型多数英文更好）

4、基础出图
 文生图（txt2img）
 图生图（img2img）
 局部重绘（Inpaint）
 扩展画布（Outpaint）
 高清放大（Hires.fix / Ultimate SD Upscale）

5、进阶控制
 ControlNet：姿势、深度、线稿、软边缘、IP-Adapter（参考图风格/人物）
 Regional Prompter / Attention Couple（分区提示词）
 FaceDetailer / After Detailer（修脸）
 多人物一致性（IP-Adapter FaceID + LoRA）
 批量出图 + 筛选

6、ComfyUI 优势
 节点工作流可保存、分享
 可做非常复杂的流水线（先出图 → 修脸 → 放大 → 加细节 → 再修）
 支持自定义节点（Manager 一键装） 
```

### 2.2 视频生成流程（本地）

1-目前主流几乎都在 ComfyUI 里完成

|      类型      |                       主要方案                       |      说明      |
| :------------: | :--------------------------------------------------: | :------------: |
|    图生视频    | AnimateDiff、SVD、CogVideoX、LTX-Video、HunyuanVideo |     最常用     |
|    文生视频    |             CogVideoX、HunyuanVideo、LTX             | 直接文字出视频 |
| 视频延长/续写  |           SVD + 延长节点、AnimateDiff 续帧           |  把短视频拉长  |
| 角色一致性视频 |          IP-Adapter + AnimateDiff + FaceID           |    人物不崩    |
|    运镜控制    |             CameraCtrl、MotionCtrl、VACE             |    推拉摇移    |
|   视频转视频   |               ControlNet + AnimateDiff               | 参考原视频动作 |

2-完整步骤

```
1.先用图片流程做出高质量关键帧（角色一致、构图好）
2.进入视频工作流（几乎全在 ComfyUI）
3.选择模型：
 想要流畅自然 → SVD / LTX / Hunyuan
 想要可控动作 → AnimateDiff + MotionLoRA
 想要长视频 → 分段生成 + 拼接

4.加入控制：
 姿势控制（OpenPose / DWPose）
 参考图控制（IP-Adapter）
 运镜控制

5.生成后处理：
 补帧（RIFE / FILM）提高帧率
 放大（视频放大模型）
 去噪、稳定、色彩统一

6.导出（mp4 / webm）
```

3-目前本地视频现实情况

```
能做出可用的 3–8 秒片段
长视频需要分段 + 后期拼接
显存要求较高（推荐 12G 以上，24G 更舒服）
```

## 三、在线图 & 视频生成

### 3.1 常见平台：

```
国内：即梦（Muse）、可灵、海螺AI、通义万相、混元、Vidu
国外：Runway Gen-3、Luma Dream Machine、Pika、Kling（国际版）、Sora（有限）
```

### 3.2 图片制作流程

```
1.注册/登录，充值积分或会员
2.选择模型版本（最新版通常更好）
3.写提示词（很多平台对中文支持已经很好）
4.上传参考图（角色一致性、风格参考）
5.调参数（比例、步数、创意度、种子）
6.生成 → 挑选 → 局部修改 / 超分
7.下载
```

### 3.3 视频制作流程

```
一、视频制作流程
-图生视频（上传关键帧）或文生视频
-设置时长、运镜、运动幅度
-角色锁定 / 参考视频（部分平台支持）
-生成后可延长、局部重绘、加镜头
-下载原片

二、对比本地：
优点：出片快、不用管显卡、模型更新快
缺点：积分贵、可控性较弱、隐私一般
```

## 四、短剧制作（完整成片）

### 4.1 说明

```
把上面生成的图/视频真正做成短剧
```

### 4.2 完整流程

```
1.前期
选题 + 受众定位
写剧本（1–3 分钟一集，强钩子、快节奏、反转）
拆分镜（每镜写清：画面、台词、情绪、镜头运动）
角色设定（外貌、服装、性格，方便后面保持一致）

2.中期（素材生产）
用本地或在线工具批量生成关键帧 / 视频片段
重点保证：人物脸一致性、服装一致性、场景统一
补拍/重做不满意的镜头

3.后期
配音（AI 配音工具：ElevenLabs、海螺、剪映、Azure 等）
配乐 + 音效
剪辑（剪映 / Premiere / CapCut）
-卡点、节奏、转场、字幕
-镜头衔接自然

调色统一
导出多平台版本（竖屏 9:16 为主）

4.发布与迭代
发抖音 / 快手 / 视频号 / 小红书
看数据（完播、互动）调整下集节奏
```

## 五 学习建议与对比

### 5.1 对比

|   项目   | 本地（ComfyUI等） | 在线（Muse等） |    短剧制作    |
| :------: | :---------------: | :------------: | :------------: |
| 上手难度 |       中高        |       低       |       中       |
|  可控性  |       最强        |      中等      |   依赖前两者   |
|   成本   |    电费 + 显卡    |   积分/会员    | 时间 + 工具费  |
| 适合阶段 |  想深挖、高质量   | 快速出片、试错 |    最终成片    |
| 推荐起点 | ComfyUI基础工作流 |  即梦 / 可灵   | 先有剧本再动手 |

### 5.2 推荐学习顺序

```
先玩在线工具，快速出结果，建立感觉
再学本地 ComfyUI，提升可控性和质量
最后结合剧本和剪辑，做成真正的短剧
```
