## 二、剧本制作


### 2.1、短剧示例剧本

```
剧名：《掀翻乐坛，重奏十年之声》
集数：第2集
类型：励志 / 音乐逆袭 / 都市情感
核心卖点：陆深找到旧琴房，却发现里面弹琴的人不是苏晚。一首《未完成的十年》揭开两人十年前未说完的真相。
```

### 2.3 、本集大纲

```
开场钩子：陆深推开旧琴房的门，钢琴声还在响，坐在琴前的却是一个陌生的短发女孩。

冲突：女孩说这是“苏老师”留给她的练习曲。陆深质问苏晚在哪，女孩却只是把一份泛黄的乐谱递过来——上面写着陆深十年前亲手改过的笔记。

高潮/反转：苏晚其实一直站在门外听着。她走进来，淡淡地问陆深：“十年前你说这曲子差一口气，现在……你还听得出那口气在哪吗？”

结尾钩子：陆深没有回答，只是坐下，当着苏晚的面把《未完成的十年》完整弹了一遍。弹到最后一段时，他停住了。苏晚的手机突然亮起，赵野发来消息：“苏晚，合作吧。不然我把十年前的事，全部抖出去。”
```

### 2.4 、分镜剧本

```
镜头1（0–7秒）

时间/地点：深夜，旧居民楼琴房门口
画面描述：陆深站在门前，门上贴着一张泛黄乐谱，标题手写《未完成的十年》。门内传来钢琴声，旋律正是昨晚那首曲子的变奏。他抬手，推开门。
镜头运动：从乐谱特写缓缓上摇到陆深侧脸，再跟他推门的动作
台词/旁白：无
情绪/音效提示：钢琴声清晰，楼道很安静
预计时长：7秒

镜头2（7–18秒）

时间/地点：琴房内
画面描述：灯光昏黄。琴前坐着一个短发女孩（小鹿），穿着旧卫衣，手指在琴键上认真移动。她听到开门声，猛地停住，有些慌张地站起来。
镜头运动：先给弹琴的手部特写，再拉成小鹿和陆深的对面中景
台词/旁白：小鹿：“你、你是……陆深？”
情绪/音效提示：钢琴声戛然而止，只剩余音
预计时长：11秒

镜头3（18–32秒）

时间/地点：琴房内
画面描述：陆深没有回答，只是走到琴旁，目光落在琴谱上。那是他十年前用红笔改过的版本，笔迹还在。小鹿小声说：“苏老师说，这是她最重要的练习曲。她让我每天都要弹。”
镜头运动：陆深手指轻轻碰了碰乐谱上的红笔字迹（特写）
台词/旁白：陆深（低声）：“她人呢？”
情绪/音效提示：沉默，只有远处的车声
预计时长：14秒

镜头4（32–45秒）

时间/地点：琴房门口 → 屋内
画面描述：苏晚靠在门框上，不知何时已经到了。她看着陆深，表情很淡。小鹿识趣地抱起自己的包，低声说“我先走了”，匆匆离开。两人独处。
镜头运动：苏晚出现在门框的剪影 → 切到陆深转头看她
台词/旁白：苏晚：“十年前你说这曲子差一口气。现在……你还听得出那口气在哪吗？”
情绪/音效提示：语气平静，却带着一点刺
预计时长：13秒

镜头5（45–65秒）

时间/地点：琴房内
画面描述：陆深没有说话，直接在琴凳上坐下。他解开袖扣，开始弹《未完成的十年》。苏晚站在一旁，静静听着。灯光只打在他们两个人身上，像回到十年前的练习室。
镜头运动：陆深弹琴的侧脸与手部交叉，偶尔切到苏晚微微收紧的手指
台词/旁白：无（只有钢琴声）
情绪/音效提示：钢琴声比之前更完整，却在最后一段突然停住
预计时长：20秒

镜头6（65–80秒）

时间/地点：琴房内
画面描述：陆深停手，低头看着琴键。苏晚的手机在沉默中亮起，屏幕上是赵野的消息：“苏晚，合作吧。不然我把十年前的事，全部抖出去。” 苏晚看着消息，眼神冷了一瞬，却把手机扣在了桌上。
镜头运动：手机屏幕特写 → 苏晚的侧脸 → 陆深抬眼看她
台词/旁白：陆深：“谁的消息？”
情绪/音效提示：安静，只有两人的呼吸声
预计时长：15秒

镜头7（80–95秒）

时间/地点：琴房内 → 黑屏
画面描述：苏晚没有回答，只是把那份泛黄的乐谱重新推回陆深面前。她说：“你先把这口气补上。补完之前，别来问我别的事。” 说完她转身往外走。陆深看着她的背影，终于开口：“苏晚，十年前的事……不是你想的那样。”
镜头运动：苏晚背影远去，门慢慢合上，留下陆深独自坐在灯下
台词/旁白：门关上的声音很轻
情绪/音效提示：余韵，黑屏前最后一声门响
预计时长：15秒
```

### 2.5 、本集结尾

```
本集结束画面：陆深独自坐在旧琴房，面前是那份《未完成的十年》，字幕浮现——第2集完

下一集预告钩子：赵野果然把旧事抖了出去。热搜爆了。苏晚站在天台，陆深的电话一直打进来，她始终没有接。

需要特别注意的一致性问题：
 苏晚仍以黑/冷色系为主
 陆深本集衬衫袖口挽起（和上集呼应）
 《未完成的十年》的旋律要和上集统一
 小鹿只是过场角色，戏份干净即可
```

### 2.6 、备注

```
参考风格/色调：继续冷色调，琴房用昏黄灯光制造怀旧感。
音乐建议：本集钢琴戏很重要，建议用同一旋律的不同完成度版本。
节奏提示：前半段偏安静对峙，后半段用钢琴和消息把情绪抬起来。
本集总时长建议控制在 90 秒左右。
```
