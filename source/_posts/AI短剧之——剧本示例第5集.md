## 二、剧本制作


### 2.1、短剧示例剧本

```
剧名：《掀翻乐坛，重奏十年之声》
集数：第5集
类型：励志 / 音乐逆袭 / 都市情感

核心卖点：匿名短信揭开十年前监控的存在，赵野放出最后底牌。苏晚选择正面回应，陆深却在关键时刻发现，短信的发送者另有其人。
```

<!--more-->

### 2.3 、本集大纲

```
开场钩子：苏晚看着手机上的匿名短信——“十年前那天晚上的监控，我还留着。” 发送时间就在几分钟前。

冲突：赵野在直播里暗示“有人藏了更劲爆的证据”，舆论再次涌向苏晚。苏晚没有躲，直接决定开一场临时线上直播。

高潮/反转：直播中，苏晚平静地弹完《未完成的十年》完整版，然后说出：“监控里的事，我可以自己讲。但在此之前，我想先问一句——发短信的人，你为什么现在才出现？”

结尾钩子：直播突然被切断。陆深在另一头查到短信的真实发送源头，脸色骤变。他给阿言只说了一句话：“不是赵野。是十年前那个本不该存在的人。”
```

### 2.4 、分镜剧本

```
镜头1（0–8秒）

时间/地点：夜晚，苏晚暂住的简陋房间
画面描述：台灯只亮一盏。苏晚坐在床边，手机屏幕亮着，匿名短信赫然显示：“十年前那天晚上的监控，我还留着。” 她盯着那行字，指尖微微收紧。
镜头运动：手机短信特写 → 苏晚低垂的眼睛
台词/旁白：无
情绪/音效提示：房间很安静，只有很轻的呼吸声
预计时长：8秒

镜头2（8–20秒）

时间/地点：赵野直播间（交叉剪辑）
画面描述：赵野坐在灯光很好的背景前，笑容得体，对镜头说：“有些真相被埋了十年，总要见光。我手里其实还有更完整的东西……只是不想把事情做绝。” 弹幕瞬间爆炸。
镜头运动：赵野面对镜头的中景 → 快速闪过的弹幕文字
台词/旁白：赵野（微笑）：“大家耐心等，好戏在后头。”
情绪/音效提示：直播间的提示音嘈杂
预计时长：12秒

镜头3（20–35秒）

时间/地点：苏晚房间
画面描述：苏晚把手机放下，走到房间角落那架简易电钢琴前。她没有犹豫，打开直播软件，按下“开始”。镜头里只有她和钢琴，背景是旧墙。
镜头运动：苏晚按下直播键的手指特写 → 她抬眼看向镜头的冷静表情
台词/旁白：苏晚（对镜头，声音平稳）：“今天只弹一首。弹完，我说监控的事。”
情绪/音效提示：直播开始的提示音很短
预计时长：15秒

镜头4（35–55秒）

时间/地点：苏晚直播画面
画面描述：苏晚开始弹《未完成的十年》。这一次她弹得完整而克制，没有多余的情绪。直播间人数疯狂上涨，弹幕从骂声渐渐变成“先听完”。
镜头运动：以苏晚侧脸和手部为主，偶尔切到观看人数跳动的小窗
台词/旁白：无（只有钢琴声）
情绪/音效提示：钢琴声干净，盖过一切杂音
预计时长：20秒

镜头5（55–72秒）

时间/地点：苏晚直播画面
画面描述：最后一个音落下。苏晚抬起头，直视镜头，说：“监控里的事，我可以自己讲。但在此之前，我想先问一句——发短信的人，你为什么现在才出现？” 她顿了顿，补了一句：“十年了。你在等什么？”
镜头运动：苏晚正面中景，眼神直视镜头
台词/旁白：同上
情绪/音效提示：话音落下后，直播间突然安静了一秒
预计时长：17秒

镜头6（72–88秒）

时间/地点：陆深所在的办公室/车上
画面描述：陆深盯着电脑屏幕，阿言正在快速敲键盘。屏幕上跳出短信追踪结果。陆深看清来源的那一刻，脸色骤然沉下。
镜头运动：电脑屏幕光打在陆深脸上 → 他握紧手机的手
台词/旁白：阿言：“陆总，查到了……真的不是赵野的号。”
陆深（低声）：“继续追。我要知道这个人现在在哪。”
情绪/音效提示：键盘声急促
预计时长：16秒

镜头7（88–105秒）

时间/地点：苏晚直播画面突然黑屏 → 陆深侧脸
画面描述：苏晚的直播毫无预兆地断开，画面变成黑屏。与此同时，陆深对着电话只说了一句：“不是赵野。是十年前那个本不该存在的人。” 画面定格在他压抑的侧脸上。
镜头运动：黑屏 → 陆深侧脸特写，慢慢暗下
台词/旁白：陆深（画外，极低）：“……她还活着？”
情绪/音效提示：突然的静默
预计时长：17秒
```

### 2.5 、本集结尾

```
本集结束画面：陆深的侧脸与黑屏交替，字幕浮现——第5集完

下一集预告钩子：苏晚的直播被强制切断后，她收到第二条匿名短信，只有一个地址和一行字：“想来拿监控，就来。一个人来。” 陆深几乎同时查到了同一个地址。

需要特别注意的一致性问题：
苏晚本集以黑色高领 + 浅色风衣为主
直播画面要干净，突出她和钢琴
“十年前那个本不该存在的人”成为新悬念点，后续需回收
```

### 2.6 、备注

```
参考风格/色调：苏晚房间偏暗、暖黄台灯；直播画面干净冷清；陆深戏份继续冷色调。
节奏提示：前半段用短信和赵野直播压气氛，中间钢琴直播是情绪高点，结尾骤然转折。
本集总时长建议控制在 100 秒左右。
音乐建议：直播弹奏部分用完整钢琴版，前后尽量少配乐，保留真实感。
```
