## 二 每个阶段的完成标准

### 2.1 第一阶段：能够独立生成图片

成功运行基础工作流，理解主要节点，知道模型文件放在哪里。

### 2.2 第二阶段：能够调整生成效果

能独立修改提示词、采样参数、图片尺寸和模型，并复用工作流。

### 2.3 第三、四阶段：能够修改和排查工作流

能根据目标选择图生图、局部重绘、ControlNet 等方法，并解决常见依赖问题。

### 2.4 第五、六阶段：能够完成可复现的项目

产出真实图片处理案例、可复用工作流，以及能够调用 ComfyUI API 的脚本。

## 三 网站文章统一规范

### 3.1 建议每篇文章固定包含以下内容：

```
1. 学习目标：本篇解决什么问题。
2. 准备工作：软件版本、模型、节点、硬件要求。
3. 操作步骤：尽量一步一图，提供准确的操作路径。
4. 关键参数：说明参数的作用及修改后的影响。
5. 运行结果：展示效果图、对比图或工作流截图。
6. 常见问题：记录实际遇到的错误和解决办法。
7. 本篇总结：说明掌握了什么，并引出下一篇。
```

### 3.2 注意事项

```
涉及模型下载、人物一致性、自定义节点和视频生成时，要特别记录模型授权、版本兼容性及显存要求。
```
