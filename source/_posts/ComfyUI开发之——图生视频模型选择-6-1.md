## 一 电脑配置及作用

```
显卡：RTX 3060 Ti（8GB VRAM）
内存：16GB
存储：500GB
已装 ComfyUI
用途：图生视频
模型：MiniMax H3 vs Wan 2.2
```

<!--more-->

## 二 模型选择

### 2.1 电脑带动能力（最关键）

|        项目         | MiniMax H3（FL2VA pruned int8） |     Wan 2.2（TI2V-5B）     | 结论（对你电脑） |
| :-----------------: | :-----------------------------: | :------------------------: | :--------------: |
|    **最低 VRAM**    |    8GB 可用（需强 offload）     |      **8GB 官方友好**      |    Wan 更轻松    |
|    **推荐 VRAM**    |          12–24GB 更稳           |      8–12GB 就很舒服       |     Wan 占优     |
|  **系统内存需求**   |       16G 偏紧（容易卡）        |          16G 够用          |    Wan 更友好    |
|    **模型体积**     |         约 40GB（整套）         |      约 18GB（5B 版）      |     Wan 更小     |
| **生成速度（8GB）** |   较慢（5秒可能 10–20 分钟）    | 明显更快（5秒约 3–9 分钟） |    Wan 快很多    |
|     **稳定性**      |     需要精细设置，容易 OOM      |      官方明确支持 8GB      |     Wan 更稳     |

结论：

```
这台电脑（8GB 显存）Wan 2.2 更好带动，跑起来更顺、更不容易爆显存。
H3 能跑，但体验会差一些（慢、吃内存）。
```

### 2.2 生成效果对比

|         维度         |         MiniMax H3         |       Wan 2.2        |   谁更好    |
| :------------------: | :------------------------: | :------------------: | :---------: |
|     **原生音频**     | ✅ 有（立体声 + 口型同步）  |    ❌ 无（纯视频）    | **H3 完胜** |
|     **画面质感**     | 更高（光影、细节、电影感） |  不错（720p 清晰）   |   H3 略强   |
|    **动作流畅度**    |       较保守，但稳定       | **更自然、动态更强** |  Wan 略强   |
|    **角色一致性**    |   **极强**（R2V 多参考）   |    较好（首尾帧）    |   H3 更强   |
| **文字 / Logo 渲染** |  **很强**（能出清晰文字）  |         较弱         |   H3 完胜   |
|     **指令遵循**     |            更好            |         良好         |   H3 略强   |
|     **最长时长**     |          4–15 秒           |       约 5 秒        |   H3 更长   |
|  **分辨率（本地）**  |     短边 768（约 1K）      |      最高 720p       |    接近     |

总结风格：

```
- H3：更“成品感”，带声音、角色稳、适合广告、口播、需要文字的场景。
- Wan 2.2：动作更灵动、生成更快，适合纯画面、动态漫、动作戏。
```

## 三 最终建议

|         你的需求         |        推荐模型         |          原因           |
| :----------------------: | :---------------------: | :---------------------: |
| **想带声音、口播、广告** |     **MiniMax H3**      |    原生音频是杀手锏     |
| **想快、稳定、多试几次** |     **Wan 2.2 5B**      | 你的 8GB 显卡跑它更轻松 |
|   **角色一致性要求高**   | MiniMax H3（用 Ref2VA） |      参考能力更强       |
|    **纯动作/动态漫**     |         Wan 2.2         |   动作更自然 + 速度快   |

综合建议（针对 3060 Ti 8GB）

```
优先把 H3 跑通（你已经在下载了），先体验带声音的效果。
如果觉得太慢或经常卡，再下 Wan 2.2 TI2V-5B 作为主力（更适合你的硬件）。
两者可以共存，根据场景切换使用。
```
